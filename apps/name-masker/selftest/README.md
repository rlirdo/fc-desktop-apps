# selftest — 合成測試資料（NameMasker 2.1）

這裡的檔案全部由 `../sample_data.py` 產生，**姓名、學號、電子郵件都是虛構的**，
不含任何真實學生或個人資料，可以安全放入版本控制與安裝包。

重新產生：

```
python sample_data.py                 # 六個 Excel／CSV 樣本
python sample_data.py selftest --pdf  # 連合成 PDF 一起重產（需要 Windows + Word）
```

`app.py --selftest` 大部分不會讀這裡的檔案，而是在暫存資料夾即時產生同樣的資料、
跑完整流程、讀回逐項驗證後刪除。**唯一的例外是
`樣本_選課名單_合成.pdf`**——PDF 沒辦法純靠 openpyxl 產生，所以放一份預先做好的
合成 PDF 供端對端測試（檔案不存在時，selftest 只測「抽字後的行解析」並印出說明）。
其他檔案是給人手動打開來看格式用的。

## 1. `樣本_Zuvio合成資料.xlsx`（仿 Zuvio「下載數據」）

44 列、**5 個表頭區塊**，涵蓋實務上遇到的每一種狀況：

| 列 | 內容 | 用來測什麼 |
| --- | --- | --- |
| 1–11 | 資料夾名稱／問題題型／是否匿名／題幹／問題敘述／正解… | 中繼列不可被誤判成表頭 |
| 12 | `學號｜姓名｜作答時間｜回答｜回答` | 區塊 1：題組問答明細 |
| 13 | 匿名作答者 | 匿名列**不編號**（A 欄寫「匿名」） |
| 14–18 | 5 位同學（學號有 **int** 也有 **str**） | 學號型別相容、首次出現順序 |
| 21 | `學號｜姓名` | 區塊 2：未作答名單 |
| 27 | `學號｜姓名｜回答` | 區塊 3：同一批人再出現 → **同一個編號** |
| 35 | `學號｜姓名｜作答時間｜總分｜第1題｜第2題` | 區塊 4：測驗題目型，答案欄是「答對／答錯」 |
| 42 | `學號｜姓名｜回答｜同組成員` | 區塊 5：2 字姓名、同組成員欄 |

自由文字裡刻意寫了「我和林大同一起討論了這題」「參考了陳曉華學姊的報告」
「和王小明討論過」，用來驗證**文字內姓名會被換成學生編號**。

處理後的期望值（`sample_data.ZUVIO_EXPECT`）：

| 項目 | 期望 |
| --- | --- |
| 區塊數 | 5 |
| 編號學生 | 7 |
| 匿名／未具名列 | 2 |
| 學號遮罩 | 16 |
| 電子郵件遮罩 | 0（本檔沒有郵件欄） |
| 姓名欄遮罩 | 14 |
| 文字內姓名替換 | 9 |
| 連結表筆數 | 7 |

要注意的兩條規則（selftest 都有驗）：

- **3 字以上的姓名**用子字串替換（「和王小明討論過」→「和 115-1_EC_1 討論過」）。
- **2 字的姓名**只有在「整段連續中文剛好等於那個名字」時才換
  （儲存格內容就是「李明」→ 換成編號；但「答對」「答錯」這種一般詞不會被動到）。

## 2. `樣本_名冊合成資料.xlsx`（名冊型）

第 1 列就是表頭，且**第 1、5 欄的表頭是 None（空白）**，第 5 欄的資料是 15 字的
中文說明（不是 email），用來驗證：

- 容忍 None 表頭
- 找得到「電子郵件」欄 → 整串改 O，長度不變
- 不是 email 的欄位**不可以**被動到

期望：1 個區塊、3 位學生、學號遮罩 3、郵件遮罩 3、姓名遮罩 3、連結表 3 筆。

## 3. `樣本_通用格式.csv`（通用 CSV）

`姓名,學號,作答` 三欄。輸出會轉存成 `.xlsx`，並在說明中註記「本檔無電子郵件欄，略過」。
期望：1 個區塊、2 位學生、學號遮罩 2、文字替換 1 處。

## 4. 2.1 新增：原始名單樣本

合成班級固定是 5 人（學號 `990054001`–`990054005`），
另有一位**不在名單**的作答者 `990054099`（模擬退選仍作答）。

| 檔案 | 內容 | 用來測什麼 |
| --- | --- | --- |
| `樣本_原始名單_含序號.xlsx` | `序號｜學號｜姓名｜班級` | 編號規則「**依序號**」 |
| `樣本_原始名單_無序號.xlsx` | 仿 e學苑匯出（含 None 表頭、電子郵件欄），**列出順序刻意與學號順序不同** | 編號規則「**依學號排序**」 |
| `樣本_原始名單.csv` | `序號,學號,姓名` | CSV 名單 |
| `樣本_選課名單_合成.pdf` | 仿東華教務系統「選課名單」，一位學生一行：`姓名+9碼學號+序號 班級`，第 3 位帶 `【註*】` | **PDF 端對端**解析 |

`sample_data.py` 另外提供兩組「抽字後的行列表」給解析器單元測試：

- `PDF_LINES_ONELINE`：pypdf 版面（姓名／學號／序號／班級都在同一行）
- `PDF_LINES_SPLIT`：PyMuPDF 版面（每個欄位各自一行，中間夾 `【註*】` 與空行）
- `PDF_LINES_BAD`：序號跳號 → 必須丟出「這份 PDF 讀不出名單…」

以及兩個**出現順序不同**的 Zuvio 合成檔（`write_zuvio_week1/2`），
用來驗證同一位學生在兩個檔案拿到同一個編號、名單外作答者兩次都是 `115-1_EC_101`。

## `--selftest` 會驗什麼

1. 課程縮寫（`^[A-Z]{2}$`、自動大寫）與學期（`^\d{3}-[12]$`）格式驗證
2. 五個區塊都被找到，統計數字與期望值完全一致
3. A 欄：每個表頭列寫「學生編號」、每個資料列的編號正確、**首次出現順序**正確
4. **跨區塊同一人同一個編號**；匿名列不編號
5. 學號欄**全部是 O 且長度不變**（int／str 都要對）
6. 姓名欄第 2 字變 O；取消勾選時姓名不動但學號／文字替換仍要做
7. 文字儲存格內容逐格比對（含「答對／答錯」不可被誤換）
8. **整張工作表不得殘留任何合成姓名**
9. 連結表標題、筆數、學號、首次出現列
10. **原檔 sha256 不變**；重複執行輸出 `02` → `03`
11. 名冊型（None 表頭、電子郵件欄）與通用 CSV
12. 錯誤處理：沒有姓名欄、課程縮寫格式錯、檔案不存在

2.1 再加上：

13. 名單解析與編號：含序號 → 依序號；無序號 → 依學號排序；CSV 名單；
    對照表三張工作表與欄位名稱；說明頁要有「再識別鑰匙／只留本機」警語
14. 對照表已存在 → **沿用不重編**；`--overwrite-codebook` 才重建；
    載入「對照表本身」直接採用；**重複學號報錯**
15. PDF：同一行版面、分行版面兩種行序都要解析正確；序號不連續／讀不到學生 → 白話錯誤；
    合成 PDF 端對端
16. **兩個出現順序不同的 Zuvio 檔 → 同一學生同一編號**；
    名單外作答者兩檔都是 `115-1_EC_101` 且**持久回寫**對照表（含「首次出現檔案」）；
    重新載入對照表後編號不變；名單內所有姓名都納入自由文字替換
17. §1.5：沒有名單時執行被擋、`--no-roster` 放行、`--roster` 與
    「設定檔記住的對照表」（拖檔模式）都能用

全部通過才會印 `SELFTEST OK` 並 `exit 0`；完整紀錄寫在
`%TEMP%\NameMasker_selftest.log`。
