# 姓名遮罩與學生編號 NameMasker 2.2 — 使用說明

> 東華大學自然資源與環境學系　仿生與環境工作坊
> 適用：Windows（`NameMasker.exe`）、macOS（`NameMasker.app`）
> 版本：**2.2.0**

把 Zuvio「下載數據」的 Excel（或名冊 xlsx、通用 CSV、**Word 文件、PDF**）一鍵變成
**可以安全拿去分析、可以放進文字雲程式、可以給助教看**的檔案。
**原始檔案一個位元組都不會被改到**，程式只會在旁邊另存一個新檔。

## 2.2 有什麼不一樣？名單與目標檔都能用 Word／PDF

| | 2.1 | **2.2** |
| --- | --- | --- |
| 名單可以是 | Excel／CSV／選課名單 PDF | 再加上 **Word（.docx）** |
| 要遮罩的目標檔 | Excel／CSV | 再加上 **Word（.docx）** 與 **PDF** |
| 選課名單 PDF | 只讀得懂「9 碼純數字學號」 | 也讀得懂**含英文字母的學號**、姓名與學號**黏在一起**、
姓名或註記**被折成兩行**、**文字層抽不到姓名**（罕用字）的列 |
| 序號不連續 | **直接拒絕**整份名單 | **照樣讀完**，只提醒「名單序號缺 12、38」 |

版面、按鈕位置與操作流程完全沒變，只是檔案選擇視窗多了 `.docx` 與 `.pdf`；
② 的按鈕字樣從「選擇 Zuvio 檔（可多選）」改成「**選擇要處理的檔案（可多選）**」（功能相同）。

## 2.1 有什麼不一樣？先載入名單！

2.0 的學生編號是「**依每個檔案內第一次出現的順序**」給的，
所以同一位同學在第 1 題的檔案是 `115-1_EC_3`、在第 2 題的檔案可能變成 `115-1_EC_7`，
**跨檔案、跨週次沒辦法對起來**（這是 2.0 已知的缺陷）。

2.1 改成：

```
① 先載入這門課的「原始名單」 →  產生「學生編號對照表」（固定編號）
② 之後每一週、每一個 Zuvio 檔都照這本對照表編號
```

同一位同學**永遠是同一個編號**，可以放心做跨週比較、成長分析。

## 一、四個步驟

### ① 載入原始名單（每學期只要做一次）

打開程式，最上面那一區就是「**① 原始名單**」：

1. 先確認右下的 **學期**（例 `115-1`）與 **課程縮寫**（2 個英文字母，例 `EC`）。
2. 按「**選擇名單…**」挑一份名單檔（支援格式見第二節）。
3. 程式會自動產生對照表，狀態列會顯示
   「已讀到 **21** 人｜編號規則：**依序號**｜對照表：`…\115-1_EC_學生名單與學生編號對照表.xlsx`」。
4. 想看對照表內容，按「**開啟對照表**」。

對照表預設存到**名單檔的同一個資料夾**，檔名固定是
`{學期}_{課程縮寫}_學生名單與學生編號對照表.xlsx`。
程式會記住這本對照表的位置，下次打開自動載入。

### ② 選要處理的檔案

按「**選擇要處理的檔案（可多選）**」，挑一個或多個
`.xlsx` / `.xlsm` / `.csv` / **`.docx`** / **`.pdf`**。
勾選框「同時遮罩姓名欄與文字內姓名」**建議一直勾著**。

### ③ 開始處理

按「**③ 開始處理**」，下方會列出每個檔案的摘要，包含
**名單內 n 人、名單外 m 人（101 起）、對照表已回寫**。

### ④ 取檔

按「**開啟輸出資料夾**」，新檔就是 **`原檔名02.xlsx`**（再跑一次是 `03`、`04`…）。

| 你選的檔 | 輸出 |
| --- | --- |
| `.xlsx` / `.xlsm` / `.csv` | `原檔名02.xlsx` |
| `.docx` | `原檔名02.docx`（版面、表格、頁首頁尾保留；少數段落的字元格式可能被統一，見〈已知限制〉） |
| `.pdf` | `原檔名02.docx`（**文字版**，不保留原版面，見第四節） |

> 設定存在 `C:\Users\你的帳號\.namemasker\settings.json`
> （學期、課程縮寫、姓名遮罩、**上次的對照表路徑**）。

## 二、名單可以是什麼格式？

### (a) Excel／CSV 名單

只要**前 5 列裡有一列同時出現「學號」和「姓名」**就讀得到，欄位順序不拘，
表頭可以有空白欄。常見的都支援：

| 來源 | 欄位範例 |
| --- | --- |
| e學苑匯出 | `學號 | 班級 | 姓名 | 電子郵件` |
| 自製名冊 | `（空）| 學號 | 姓名 |（空）` |
| 自製名冊（含序號） | `序號 | 學號 | 姓名 | 班級` |

可另外有「**序號**」「**班級／系級／系所＋年級**」「電子郵件」欄。

### (b) Word 名單（`.docx`，2.2 新增）

* 名單是**一張表格**：只要表頭同一列有「學號」和「姓名」就讀得到
  （跟 Excel 同一套規則，可另有 序號、班級）。
* 名單**沒有表格**、只是一行一位同學的段落：程式會自動改用下面 (c) 的行解析。
* 舊的 `.doc` 讀不了 → 會提醒你「請先用 Word 另存為 `.docx`」。

### (c) 東華教務系統「選課名單／成績登記表」PDF

從教務系統下載的**文字型** PDF（不是掃描影像）可以直接丟進來。
程式用 `pypdf` 抽字，以「9 碼學號」為錨點，把姓名／序號／班級抓出來，
`【註*】` 之類的註記、表頭與頁尾會自動忽略。**多頁名單的序號會自動接續。**

2.2 起支援的學號形狀（都是 9 個字元）與列的排法：

| 形狀 | 例子 |
| --- | --- |
| 9 碼純數字 | `990054043` |
| 第 6 碼是英文字母 | `99001A001` |
| 第 1 碼是英文字母 | `A99000001` |

| 這一列長什麼樣 | 程式怎麼處理 |
| --- | --- |
| 姓名、學號、序號**黏在一起**（`王小明9900010011`） | 自動拆開（序號 1～3 位都可以） |
| 姓名中間有空白（族名、複姓分寫） | 空白保留在姓名裡 |
| `【註*】` 夾在姓名與學號之間 | 直接忽略 |
| `【註*】`**被折成兩行** | 自動接回去再解析 |
| 中文名＋英文名**被折成兩行** | 自動把兩行接成同一個姓名 |
| 整列**沒有姓名**（罕用字，PDF 文字層本來就沒有） | **仍然保留這位學生**，姓名欄空白，並提醒你到對照表補上 |

讀不出來時會顯示白話訊息：
**「這份名單讀不出任何學生，請改用 Excel 名單（需有 學號、姓名 欄）」**
（掃描影像檔會看到這句；請改用 Excel 名單。）

#### 讀不到姓名怎麼辦？

訊息區會出現：

> 序號 6 的學生在名單檔中讀不到姓名（可能是罕用字），請在對照表補上姓名；遮罩仍會依學號進行。

處理方式：**打開對照表 xlsx，在那一列的「姓名」欄自己補上**，存檔即可。
不補也沒關係 —— 那位同學的**學號照樣會被遮罩**、學生編號照樣固定，
只是「文字裡提到他的名字」不會被換成編號。

#### 序號缺號怎麼辦？

2.2 起**不會再因為序號不連續就拒絕整份名單**。訊息區會出現：

> 名單序號缺 12、38，可能有學生沒讀到，請對照原名單人數。

請拿原始名單核對人數。若人數對得上（例如原本就有人退選、教務系統跳號），
可以直接繼續用；若人數少了，就改用 Excel 名單。

### (d) 既有的「學生編號對照表」

直接選對照表檔也可以（程式看到有「學生編號」欄就**原樣採用、不重新編號**）。
換一台電腦、換一位助教接手時就用這招。

## 三、學生編號是怎麼給的？

| 情況 | 規則 |
| --- | --- |
| 每位都有「序號」且不重複（**允許缺號**） | `{學期}_{課程縮寫}_{序號}`，例 `115-1_EC_7` |
| 沒有序號欄，或序號**有重複／有人讀不到序號** | 依**學號字串遞增排序**給 1..N |
| 不在名單的作答者（退選、旁聽、跨班） | 從 **101** 開始遞增，例 `115-1_EC_101` |

**名單外作答者會被「持久登記」**到對照表的「名單外作答者」工作表，
記下 `學生編號｜學號｜姓名｜首次出現檔案`。下一週同一個人再出現，
還是拿到同一個 101 號——**跨檔跨週一致**。

### 對照表長什麼樣子

`{學期}_{課程縮寫}_學生名單與學生編號對照表.xlsx` 有三張工作表：

| 工作表 | 欄位 |
| --- | --- |
| **學生編號對照** | `序號｜學生編號｜學號｜姓名｜班級` |
| **名單外作答者** | `學生編號｜學號｜姓名｜首次出現檔案` |
| **說明** | 編號規則與警語 |

> ### ⚠ 對照表含真名與學號＝再識別鑰匙，只留本機
> 這個檔案可以把 `115-1_EC_7` 換回真實姓名與學號，屬於個人資料。
> **不要**上傳雲端、**不要**寄給別人、**不要**放進 GitHub、**不要**丟給任何 AI 服務。
> 學期結束、分析完成後請刪除。

## 四、程式到底做了什麼？

| 做的事 | 前 | 後 |
| --- | --- | --- |
| A 欄插入「**學生編號**」 | （沒有這一欄） | `115-1_EC_1`、`115-1_EC_2`…（來自對照表） |
| **學號**每個字元改成 O | `990054043` | `OOOOOOOOO`（長度一樣） |
| **電子郵件**每個字元改成 O | `abc@gms.ndhu.edu.tw` | `OOOOOOOOOOOOOOOOOOO` |
| **姓名**第 2 個字改成 O | 王小明 | 王O明 |
| 回答裡提到**同學的名字** | 「我和王小明討論」 | 「我和 115-1_EC_1 討論」 |
| 回答裡夾帶的學號／郵件 | 「我的學號是 990054043」 | 「我的學號是 OOOOOOOOO」 |
| 新增工作表 | — | **學生編號連結姓名** |

幾個重要的設計：

- **一個人只有一個編號。** Zuvio 匯出的同一張工作表常常有好幾個區塊
  （作答明細、未作答名單、各子題彙總、測驗題目成績…），程式會把**每一個**
  有「姓名」的表頭都找出來，同一位同學不管出現在哪個區塊、哪個檔案，
  都拿到**對照表裡那一個**編號。
- **名單內所有同學的姓名都會被納入自由文字替換**，
  就算這個檔案的姓名欄沒出現那個人，別人回答裡提到他也會被換成編號。
- **匿名作答者不編號**，A 欄會寫「匿名」。
- **沒有電子郵件欄就跳過**（Zuvio 匯出通常沒有；名冊匯出才有），
  處理結果會寫一行「本檔無電子郵件欄，略過」，這是正常的，不是錯誤。
- **測驗題目型**的匯出（答案欄是「答對／答錯」）也支援。2 個字的姓名只有在
  「整段中文剛好等於那個名字」時才會被換掉，才不會把「答對」「原理」這種
  一般詞誤認成人名。

### 執行摘要怎麼看

| 摘要那一行 | 意思 |
| --- | --- |
| 找到 N 個資料區塊 | 這張工作表裡有 N 個「姓名」表頭 |
| 編號學生 N 位：名單內 n 人、名單外作答者 m 人 | 這個檔案裡有幾位同學、其中幾位不在名單 |
| 匿名／未具名列 N 列 | 匿名作答者，沒有編號 |
| 遮罩學號 N 筆、電子郵件 N 筆 | 每個字元都改成 O 的儲存格數 |
| 姓名欄遮罩 N 筆 | 姓名欄第 2 字改成 O 的儲存格數 |
| 文字內姓名改成學生編號 N 處 | 見下面說明 |
| 對照表「學生編號連結姓名」N 筆 | 這個檔案裡出現的同學數 |
| 學生編號對照表：…（已回寫名單外作答者） | 這次有新的名單外作答者被登記 |

**⚠️「文字內姓名改成學生編號」的數字很大是正常的，不是誤換。**

一般的問答題檔，這個數字通常是 0 到十幾處。
但**多選題／單選題的匯出**可能會出現上千處——實測普通化學某一週的多選題檔就有
**1,251 處**。原因是：Zuvio 多選題的匯出在作答明細後面，還附了一大塊
「**各選項分別由哪些學生選擇**」的統計區塊，那個區塊裡**每一格的內容就是一個
學生的姓名**（而且不在「姓名」欄裡）。程式一律把這些整格的姓名換成該生的學生編號。
看到上千處，代表程式有把統計區塊一起清乾淨，可以放心。

### Word（`.docx`）目標檔怎麼處理？（2.2 新增）

適合拿來遮罩**作業回饋單、分組名單、點名表、評語表**這類 Word 檔。

| 遮到哪裡 | 說明 |
| --- | --- |
| 本文段落 | 包含被 Word 拆成好幾段 run 的姓名（複製貼上、改過字型的字常常會這樣） |
| 表格 | 含**巢狀表格**（表格裡的表格） |
| 頁首、頁尾 | 含首頁專用、奇偶頁專用的頁首頁尾 |

規則與 Excel 的「自由文字」一樣：**姓名 → 學生編號**、學號與電子郵件 → 等長的 O。
**版面、表格、圖片、段落樣式都保留**，輸出 `原檔名02.docx`。
（唯一的例外：姓名被 Word 拆在同一段落的多個 run 時，那一段的字元層級格式會統一，見〈已知限制〉。）

> Word 檔沒有「姓名欄」的概念，所以不會有「第 2 字改 O」，
> 一律換成學生編號（這樣最不會漏）。

### PDF 目標檔怎麼處理？（2.2 新增）

PDF 是「印好的紙」，沒辦法在原版面上改字，所以程式的做法是：

```
PDF →（抽出文字）→ 逐行遮罩 → 另存 原檔名02.docx（文字版）
```

* 輸出檔的**第一段**會寫明：「本檔為 PDF 抽出文字後的遮罩版，不保留原版面。」
* 如果這份 PDF 本身就是一份**讀得懂的名單**，輸出檔最後會再附一張遮罩後的表：
  `學生編號｜遮罩學號｜遮罩姓名｜班級`（姓名是「王O明」這種第 2 字遮罩）。
* **掃描影像的 PDF 抽不出文字**，會出現白話訊息請你改用原始的 Word／Excel 檔，
  或先用有 OCR 的軟體轉成文字型 PDF。

> 原版面重要（要拿去存檔、要蓋章）時，請改用**原始的 Word 檔**來遮罩，
> 遮完再自己另存成 PDF。

### 遮完會自我檢查

Word／PDF 的遮罩做完後，程式會**再把輸出檔讀一遍**，
確認裡面沒有殘留名單上的任何姓名（≥2 字）或學號。

* 沒殘留 → 摘要顯示「自我檢查：輸出檔沒有殘留名單內的姓名或學號 ✔」
* 有殘留 → 顯示「⚠ 還有 n 位同學的姓名、m 個學號殘留」，請人工再看一次
  （通常是名單上的姓名與檔案裡的寫法不同，例如中間多了空白或用了英文名）。

## 五、換課程、名單改版（加退選）怎麼辦？

| 情況 | 怎麼做 |
| --- | --- |
| **換一門課**（例如 EC → GC） | 改「課程縮寫」與「學期」→ 按「選擇名單…」挑新課的名單。程式會在新名單的資料夾產生新的對照表，兩門課互不影響。 |
| **加簽進來的同學** | 拿新版名單重新產生對照表：勾選「**用新名單重新編號（覆寫既有對照表）**」再按「產生／更新對照表」。⚠ 序號會整批重排，**之前算過的資料要一起重跑**。 |
| **退選的同學還是有舊作業** | 不用動名單。他不在名單裡，會自動拿到 101 起的編號並登記在「名單外作答者」，每一週都同一個號。 |
| **只是補上班級、改錯字** | 直接在對照表的「學生編號對照」工作表上手動改（**不要動學生編號欄**），存檔即可。 |
| **換電腦／換助教** | 把對照表複製過去，在①按「選擇名單…」直接選那本對照表。 |

> 建議：**學期中不要覆寫對照表**。編號一旦公布或用在分析裡，就讓它固定到期末。

## 六、更快的用法：把檔案拖到程式圖示上

在檔案總管裡，把一個或多個 Excel 檔**拖到 `NameMasker.exe` 的圖示上放開**，
程式會用**上次記住的對照表**與學期／課程縮寫直接處理完，然後跳一個結果視窗。
（如果還沒載入過任何名單，會跳訊息請你先開程式載入名單。）

命令列（給進階使用者／自動化）：

```bat
:: 產生／更新對照表，不處理檔案
NameMasker.exe --roster 名單.pdf --course EC --semester 115-1 --make-codebook-only

:: 用名單處理檔案（對照表存在就沿用）
NameMasker.exe Q01.xlsx Q02.xlsx --course EC --semester 115-1 --roster 名單.xlsx

:: 直接指定對照表
NameMasker.exe Q01.xlsx --course EC --semester 115-1 --codebook 115-1_EC_學生名單與學生編號對照表.xlsx

:: 用新名單重新編號（覆寫對照表）
NameMasker.exe --roster 新名單.xlsx --course EC --semester 115-1 --make-codebook-only --overwrite-codebook

:: 真的沒有名單（2.0 的舊行為，不建議）
NameMasker.exe Q01.xlsx --course EC --semester 115-1 --no-roster

NameMasker.exe --selftest        :: 自我測試，成功會回傳 0
NameMasker.exe --version         :: 顯示 NameMasker 2.1.0
```

| 旗標 | 意思 |
| --- | --- |
| `--roster 檔案` | 原始名單（`.xlsx` / `.xlsm` / `.csv` / `.pdf`） |
| `--codebook 檔案` | 直接指定既有的學生編號對照表 |
| `--make-codebook-only` | 只產生／更新對照表，不處理 Zuvio 檔 |
| `--overwrite-codebook` | 用新名單重新編號，覆寫既有對照表 |
| `--no-roster` | 沒有名單，改依檔案內出現順序編號（同一學生在不同檔案會不同號） |
| `--course` / `-c`、`--semester` / `-s` | 課程縮寫、學期 |
| `--no-mask-names` | 只做編號與學號／郵件遮罩，姓名欄保持原樣（不建議） |

**沒有 `--roster`／`--codebook`、設定檔也沒記住對照表時，一定要加 `--no-roster` 才會執行**，
否則程式會擋下來並提示先載入名單（GUI 是勾「沒有名單，改依檔案內出現順序編號」）。

設環境變數 `NAMEMASKER_NO_DIALOG=1` 就不會跳訊息框（給排程／CI 用）。

## 七、⚠️ 另一把鑰匙：「學生編號連結姓名」工作表

新檔的最後一張工作表叫 **「學生編號連結姓名」**，內容是：

學生編號 | 姓名 | 學號（原） | 電子郵件（原） | 首次出現列

**這張表和對照表一樣是「再識別鑰匙」。**

> ### 請務必遵守
> 1. 這個檔案**只能留在自己的電腦**。
> 2. **不要**上傳雲端硬碟、**不要**寄給別人、**不要**放進 GitHub、

## 九、常見問題

**Q：按「開始處理」沒反應／按鈕是灰的？**
A：2.1 一定要先在①載入名單（或勾「沒有名單，改依檔案內出現順序編號」），
而且②要至少選一個檔案，按鈕才會亮。

**Q：出現「這份名單讀不出任何學生」？**
A：多半是掃描影像的 PDF（沒有文字層）。請改用 Excel 名單
（只要有「學號」「姓名」兩欄就好）。
2.2 起**序號不連續已經不會再被拒絕**，只會提醒你「名單序號缺 …」。

**Q：名單讀進來，有人的姓名是空白？**
A：那位同學的名字在 PDF 的文字層裡本來就抽不到（通常是罕用字）。
請打開對照表 xlsx，在那一列的「姓名」欄自己補上。
不補也可以——他的**學號照樣會被遮罩**、學生編號照樣固定，
只是別人文章裡提到他的名字時不會被換成編號。

**Q：Word 名單讀不到？**
A：(1) 舊的 `.doc` 不支援，請先用 Word 另存為 `.docx`；
(2) 表格的表頭要在同一列出現「學號」和「姓名」；
(3) 沒有表格時，程式會改用「一行一位同學」的解析方式。

**Q：PDF 遮罩完為什麼變成 Word？**
A：PDF 沒辦法在原版面上改字。程式抽出文字、逐行遮罩後，
另存成 `原檔名02.docx`（文字版，第一段有註明）。
要保留版面的話，請改用**原始的 Word 檔**遮罩，遮完自己另存成 PDF。

**Q：摘要出現「⚠ 還有 n 位同學的姓名殘留」？**
A：代表自我檢查在輸出檔裡還找到名單上的姓名。
通常是檔案裡的寫法和名單不一樣（中間多空白、用了英文名、用了別字）。
請人工打開輸出檔確認，必要時手動改掉。

**Q：名單裡有重複學號？**
A：程式會擋下來，請先修正名單再產生對照表。

**Q：對照表已經存在，我又按了一次「產生／更新對照表」？**
A：預設會**沿用既有編號**（不重編），並保留名單外作答者登記。
要重新編號請勾「用新名單重新編號（覆寫既有對照表）」。

**Q：出現「整張工作表都找不到『姓名』欄位」怎麼辦？**
A：程式是靠「姓名」兩個字找表頭的。請打開 Excel 確認標題列有一格的內容
就是「姓名」（不要寫成「學生姓名／名字／Name」），改好存檔再跑一次。

**Q：出現「無法開啟檔案…正被 Excel 開啟中」？**
A：先把那個 Excel 檔（或對照表）關掉再執行。

**Q：輸出檔為什麼叫 `xxx02.xlsx`？再跑一次會蓋掉嗎？**
A：不會。第一次是 `02`，再跑一次會是 `03`、`04`…，原檔永遠不動。

**Q：舊的 `.xls` 可以嗎？**
A：不行，請先用 Excel「另存新檔」成 `.xlsx`。

**Q：處理後學號變成一串 O，我要怎麼知道是誰？**
A：用 A 欄的學生編號，去對照表或「學生編號連結姓名」工作表查（見第三、七節的警語）。

**Q：資料會不會被上傳？**
A：不會。程式**完全離線**，只讀寫你電腦上的檔案，沒有任何連網功能。

## 十、給維護者

```
apps/name-masker/
├── app.py                 GUI／CLI 入口、--selftest、--version
├── roster.py              名單解析（Excel／CSV／Word／PDF）、編號、對照表讀寫、名單外登記
│                          ★ 與 apps/homework-wordcloud/core/roster.py 完全同步（只差檔頭 docstring）
├── core_mask.py           遮罩核心：process_workbook(src, course, sem, mask_names, codebook=) -> Report
├── doc_mask.py            Word／PDF 目標檔遮罩：process_document(...) -> DocReport
├── sample_data.py         合成測試資料（零真實個資），`python sample_data.py selftest --pdf` 重產樣本
├── build.spec             PyInstaller（Windows onefile / macOS .app）
├── requirements.txt       openpyxl、pypdf、python-docx
├── docx_parts.keep        佔位檔：讓封裝內的 docx/parts/ 真實存在（macOS 的 ".." 解析）
├── icon.ico / icon.png / make_icon.py
└── selftest/              合成樣本檔（樣本_選課名單_合成.pdf、樣本_選課名單_合成_黏連格式.pdf）
```

主要 API：

```python
cb, msgs = roster.build_codebook(roster_path=..., codebook_path=..., semester="115-1",
                                 course="EC", overwrite=False)   # -> roster.Codebook
data = roster.parse_roster(path)        # -> RosterData(records=[Student], notes=[...])
students = roster.assign_codes(data, "115-1", "EC")   # 就地編號；data.notes 會補上提醒

rep = core_mask.process_workbook(src, "EC", "115-1", mask_names=True, codebook=cb)
rep = doc_mask.process_document(src, "EC", "115-1", codebook=cb)   # .docx / .pdf
cb.register_outsider(sid, name, src)   # 名單外作答者（101 起）；cb.save() 回寫
```

`app.process_any(path, course, sem, mask_names, codebook)` 會依副檔名自動分派到
`core_mask.process_workbook`（Excel／CSV）或 `doc_mask.process_document`（Word／PDF）。

打包與驗收：

```bat
set PYTHONIOENCODING=utf-8
python app.py --selftest
pyinstaller --noconfirm build.spec
dist\NameMasker.exe --selftest
```

`--selftest` 共 15 段，在 `console=False` 下也會把完整紀錄寫到
`%TEMP%\NameMasker_selftest.log`，並用回傳碼 0／1 表示成功與否。

**已知限制**

- PDF 只支援**文字型**（掃描影像檔無法解析，會請使用者改用 Excel 名單）。
- PDF 解析以「9 個字元的學號」為錨點，形狀寫在 `roster.SID_SHAPES`
  （`\d{9}`、`\d{5}[A-Za-z]\d{3}`、`[A-Za-z]\d{8}`）；其他學校的格式加在這個常數裡即可。
- 學號後面黏 1～3 位序號時，若同一串同時拆得出兩種合法解讀（例如
  `姓名A+8碼` 與 `姓名 + 9碼 + 1碼序號`），程式靠「序號＝上一筆＋1」判斷；
  名單**從中間缺號**又剛好卡在這種列時有可能拆錯，請用摘要的人數核對。
- 合成 PDF 樣本 `selftest\樣本_選課名單_合成.pdf`、`樣本_選課名單_合成_黏連格式.pdf`
  是用 Word COM 產生的（`sample_data.write_roster_pdf_via_word`、
  `write_glued_pdf_via_word`，需要 Windows + Word）；
  沒有這些檔時 `--selftest` 只測「抽字後的行解析」，不做端對端測試。
- Word 目標檔遮罩時，若姓名被拆在多個 run，該段落會被「整段改寫放回第一個 run」，
  **那一段內部的字元層級格式（例如某幾個字變紅色）會統一成第一個 run 的格式**；
  段落層級的樣式、表格、圖片都不受影響。
- PDF 目標檔輸出的是**文字版 docx**，不保留原版面、圖片與印章。
- 2 個字的姓名只有在「整段中文剛好等於那個名字」時才會被替換
  （避免把「答對」「原理」誤認成人名），所以「這週和李明同組」這種句子不會被換。
- 對照表是用檔案系統當儲存體，**同時有兩個程式在寫同一本對照表**時可能互相覆蓋；
  請一次只開一個 NameMasker，並在寫入前關掉 Excel。
