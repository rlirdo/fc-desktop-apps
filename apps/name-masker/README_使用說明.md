# 姓名遮罩與學生編號 NameMasker 2.0 — 使用說明

> 東華大學自然資源與環境學系　仿生與環境工作坊
> 適用：Windows（`NameMasker.exe`）、macOS（`NameMasker.app`）
> 版本：**2.0.0**

把 Zuvio「下載數據」的 Excel（或名冊 xlsx、通用 CSV）一鍵變成**可以安全拿去分析、
可以放進文字雲程式、可以給助教看**的檔案。
**原始檔案一個位元組都不會被改到**，程式只會在旁邊另存一個新檔。

---

## 一、三個步驟就好

1. **打開程式**（雙擊 `NameMasker.exe`），確認上方兩個欄位：
   - **學期**：例如 `115-1`（3 位數字 + 連字號 + 1 或 2）
   - **課程縮寫**：**2 個英文字母**，會自動變大寫。環境化學就填 `EC`
   - 下面的勾選框「同時遮罩姓名欄與文字內姓名」**建議一直勾著**
2. 按「**選擇檔案（可多選）**」，挑一個或多個 `.xlsx` / `.xlsm` / `.csv`，按「**開始處理**」。
3. 看下方「處理結果」的摘要，按「**開啟輸出資料夾**」就能看到新檔 **`原檔名02.xlsx`**。

設定會自動記住（存在 `C:\Users\你的帳號\.namemasker\settings.json`），下次打開就是上次的值。

---

## 二、程式到底做了什麼？

以 Zuvio「下載數據」的檔案為例，處理後的新檔會變成這樣：

| 做的事 | 前 | 後 |
| --- | --- | --- |
| A 欄插入「**學生編號**」 | （沒有這一欄） | `115-1_EC_1`、`115-1_EC_2`… |
| **學號**每個字元改成 O | `411354043` | `OOOOOOOOO`（長度一樣） |
| **電子郵件**每個字元改成 O | `abc@gms.ndhu.edu.tw` | `OOOOOOOOOOOOOOOOOOO` |
| **姓名**第 2 個字改成 O | 王小明 | 王O明 |
| 回答裡提到**同學的名字** | 「我和王小明討論」 | 「我和 115-1_EC_1 討論」 |
| 新增工作表 | — | **學生編號連結姓名** |

幾個重要的設計：

- **一個人只有一個編號。** Zuvio 匯出的同一張工作表常常有好幾個區塊
  （作答明細、未作答名單、各子題彙總、測驗題目成績…），程式會把**每一個**
  有「姓名」的表頭都找出來，同一位同學不管出現在哪個區塊，都拿到**同一個編號**。
  編號順序就是**第一次出現的順序**。
- **匿名作答者不編號**，A 欄會寫「匿名」。
- **沒有電子郵件欄就跳過**（Zuvio 匯出通常沒有；名冊匯出才有），
  處理結果會寫一行「本檔無電子郵件欄，略過」，這是正常的，不是錯誤。
- **測驗題目型**的匯出（答案欄是「答對／答錯」）也支援。2 個字的姓名只有在
  「整段中文剛好等於那個名字」時才會被換掉，才不會把「答對」「原理」這種
  一般詞誤認成人名。

### 執行摘要怎麼看

處理完，下方「處理結果」會列出這幾個數字：

| 摘要那一行 | 意思 |
| --- | --- |
| 找到 N 個資料區塊 | 這張工作表裡有 N 個「姓名」表頭（作答明細、未作答名單、各子題彙總…） |
| 編號學生 N 位 | 這個檔案裡總共有幾位不重複的同學 |
| 匿名／未具名列 N 列 | 匿名作答者，沒有編號 |
| 遮罩學號 N 筆、電子郵件 N 筆 | 每個字元都改成 O 的儲存格數 |
| 姓名欄遮罩 N 筆 | 姓名欄第 2 字改成 O 的儲存格數 |
| 文字內姓名改成學生編號 N 處 | 見下面說明 |
| 對照表「學生編號連結姓名」N 筆 | 等於「編號學生 N 位」 |

**⚠️「文字內姓名改成學生編號」的數字很大是正常的，不是誤換。**

一般的問答題檔，這個數字通常是 0 到十幾處（同學在回答裡提到別的同學時才會有）。
但**多選題／單選題的匯出**可能會出現上千處——實測普通化學某一週的多選題檔就有
**1,251 處**。原因是：Zuvio 多選題的匯出在作答明細後面，還附了一大塊
「**各選項分別由哪些學生選擇**」的統計區塊，那個區塊裡**每一格的內容就是一個
學生的姓名**（而且不在「姓名」欄裡）。程式一律把這些整格的姓名換成該生的學生編號，
所以數字會等於「所有選項的人次總和」。

**這正是我們要的去識別化**：如果不換，那些統計格會留著一整片真實姓名，
等於前面的遮罩全部白做。看到上千處，代表程式有把統計區塊一起清乾淨，可以放心。
摘要那一行後面也標了「（含整格為姓名的統計儲存格）」提醒這件事。

## 三、⚠️ 最重要的一件事：「學生編號連結姓名」工作表

新檔的最後一張工作表叫 **「學生編號連結姓名」**，內容是：

```
學生編號 | 姓名 | 學號（原） | 電子郵件（原） | 首次出現列
```

**這張表是「再識別鑰匙」——有了它就能把 `115-1_EC_7` 換回真實姓名與學號。**

> ### 請務必遵守
> 1. 這個檔案**只能留在自己的電腦**（最好放在有密碼的使用者資料夾裡）。
> 2. **不要**上傳雲端硬碟、**不要**寄給別人、**不要**放進 GitHub、
>    **不要**丟給任何 AI 服務。
> 3. 要把資料給別人看、要做文字雲、要放進簡報時，
>    **請先把「學生編號連結姓名」這張工作表刪掉**，只留下編號版的資料。
> 4. 學期結束、分析完成後，請把含有這張表的檔案刪除。

處理完的檔案若要交給「學生作業文字雲」程式，直接放進它的 `input\` 資料夾即可；
文字雲程式只會用到 A 欄的學生編號。

## 四、更快的用法：把檔案拖到程式圖示上

在檔案總管裡，把一個或多個 Excel 檔**拖到 `NameMasker.exe` 的圖示上放開**，
程式會用**上次記住的學期／課程縮寫**直接處理完，然後跳一個結果視窗。
適合每週固定的例行工作。

命令列（給進階使用者／自動化）：

```bat
NameMasker.exe 檔案.xlsx --course EC --semester 115-1
NameMasker.exe 檔案1.xlsx 檔案2.xlsx --course GC --semester 115-2 --no-mask-names
NameMasker.exe --selftest        :: 自我測試，成功會回傳 0
NameMasker.exe --version         :: 顯示 NameMasker 2.0.0
```

- `--no-mask-names`：只做編號與學號／郵件遮罩，姓名欄保持原樣（不建議）。
- 設環境變數 `NAMEMASKER_NO_DIALOG=1` 就不會跳訊息框（給排程／CI 用）。

## 五、第一次打開被擋住？

**Windows（SmartScreen）**
畫面出現藍色視窗「Windows 已保護您的電腦」：
按「**其他資訊**」→ 再按「**仍要執行**」。
（因為這是自行開發、沒有花錢買憑證簽章的程式，不是病毒。）

**macOS（Gatekeeper）**
出現「無法打開，因為無法驗證開發者」：
在 `NameMasker.app` 上**按住 Control 點一下** → 選「**打開**」→ 再按一次「**打開**」。
或到「系統設定 → 隱私權與安全性」，找到剛才被擋下的項目按「**仍要打開**」。

## 六、常見問題

**Q：出現「整張工作表都找不到『姓名』欄位」怎麼辦？**
A：程式是靠「姓名」兩個字找表頭的。請打開 Excel 確認標題列有一格的內容
就是「姓名」（不要寫成「學生姓名／名字／Name」），改好存檔再跑一次。

**Q：出現「無法開啟檔案…正被 Excel 開啟中」？**
A：先把那個 Excel 檔關掉再執行。

**Q：輸出檔為什麼叫 `xxx02.xlsx`？再跑一次會蓋掉嗎？**
A：不會。第一次是 `02`，再跑一次會是 `03`、`04`…，原檔永遠不動。

**Q：舊的 `.xls` 可以嗎？**
A：不行，請先用 Excel「另存新檔」成 `.xlsx`。

**Q：CSV 可以嗎？**
A：可以，第 1 列要有「姓名」。輸出會是 `.xlsx`。

**Q：為什麼「文字內姓名替換」是 0 處？**
A：代表同學的回答裡沒有提到別的同學的名字，很正常。

**Q：那為什麼有的檔案是 1,251 處這麼多？**
A：那是多選題的匯出，裡面附了「各選項由哪些學生選擇」的統計區塊，整格就是一個
姓名，全部被換成學生編號了。這是正確的去識別化，詳見第二節「執行摘要怎麼看」。

**Q：處理後學號變成一串 O，我要怎麼知道是誰？**
A：用 A 欄的學生編號，去「學生編號連結姓名」工作表查（見第三節的警語）。

**Q：資料會不會被上傳？**
A：不會。程式**完全離線**，只讀寫你電腦上的檔案，沒有任何連網功能。

## 七、給維護者

```
apps/name-masker/
├── app.py                 GUI／CLI 入口、--selftest、--version
├── core_mask.py           核心：process_workbook(src, course_code, semester, mask_names) -> Report
├── sample_data.py         合成測試資料（零真實個資）
├── build.spec             PyInstaller（Windows onefile / macOS .app）
├── requirements.txt
├── icon.ico / icon.png / make_icon.py
└── selftest/              合成樣本檔
```

打包與驗收：

```bat
python app.py --selftest
pyinstaller --noconfirm build.spec
dist\NameMasker.exe --selftest
```

`--selftest` 在 `console=False` 下也會把完整紀錄寫到
`%TEMP%\NameMasker_selftest.log`，並用回傳碼 0／1 表示成功與否。
