# 姓名遮罩 NameMasker　使用說明

> 東華大學自然資源與環境學系　仿生與環境工作坊
> 版本 1.0.0

把 Excel 名單裡的姓名，**第 2 個字改成大寫的 O**（王小明 → 王O明），
做好的名單放在新的工作表，並且**另存成一個新檔案**。
**你原本的檔案一個字都不會被改到。**

---

## 一、它到底做了什麼？

1. 打開你指定的 Excel 檔，只看**第 1 個工作表**。
2. 在**第 1 列（標題列）**找標題叫「姓名」的那一欄
   （找不到完全相同的，才退而求其次找標題裡「含有姓名兩個字」的欄，例如「學生姓名」）。
3. 從第 2 列開始，把中文姓名的第 2 個字換成 O：
   - 王小明 → 王O明
   - 李明 → 李O
   - 歐陽小花 → 歐O小花
   - Mary Chen → 不變（沒有中文就不動）
   - 空白 → 不變
4. 遮好的內容放進一個**新工作表**，名字是「原工作表名_遮罩」。
5. 整本另存成 **「原檔名02.xlsx」**，放在跟原檔**同一個資料夾**。
   如果 02 已經存在，就自動存成 03、04……

> 提醒：只有「姓名」那一欄會被遮，其他欄位（分數、備註、學號…）都原樣保留。

---

## 二、怎麼用（三種方式，挑一種）

### 方式 1：雙擊開視窗（最推薦）
1. 雙擊 `NameMasker.exe`。
2. 按 **「選擇 Excel 檔（可多選）」**，可以按住 `Ctrl` 一次選很多個檔。
3. 按 **「開始遮罩」**。
4. 下面的「處理結果」會顯示每個檔案遮了幾筆、存到哪裡。
5. 按 **「開啟輸出資料夾」** 就會跳出檔案總管，新檔案就在裡面。

### 方式 2：把檔案拖到圖示上
直接把一個（或多個）Excel 檔案**拖曳**到 `NameMasker.exe` 的圖示上放開，
程式會直接處理完，跳一個小視窗告訴你結果，按「確定」就結束。

### 方式 3：命令列
```
NameMasker.exe 檔案.xlsx
```

## 三、第一次打開出現藍色警告怎麼辦？

### Windows：「Windows 已保護您的電腦」（SmartScreen）
這是因為這支小程式沒有花錢買數位簽章，不是有病毒。
1. 點畫面中的 **「其他資訊」**。
2. 再點 **「仍要執行」**。
之後再打開就不會再問了。

如果是從網路下載的檔案，也可以先：
在檔案上按右鍵 →「內容」→ 最下面若有「解除封鎖」就打勾 → 確定。

### macOS：「無法打開，因為無法驗證開發者」（Gatekeeper）
1. 在 `NameMasker.app` 上**按右鍵（或 Control + 點一下）**→ 選 **「打開」**。
2. 跳出的視窗再按一次 **「打開」**。
（直接雙擊會被擋，用右鍵「打開」才會出現放行按鈕。）
若仍被擋：系統設定 →「隱私權與安全性」→ 往下找到被阻擋的提示 → 按 **「仍要打開」**。

## 四、常見問題

| 狀況 | 原因與處理 |
| --- | --- |
| 「第 1 個工作表的第 1 列找不到『姓名』欄位」 | 標題列不是第 1 列，或姓名欄標題寫成「學生」「名字」。請把那一欄的標題改成 **姓名**，或把標題列搬到第 1 列。 |
| 「無法開啟檔案…正被 Excel 開啟中」 | 請先在 Excel 裡把該檔案關掉再執行。 |
| 「只支援 .xlsx / .xlsm」 | 舊的 `.xls` 請先用 Excel「另存新檔」成 `.xlsx`。 |
| 遮罩筆數比我想的少 | 英文名字、空白、純數字（例如用學號代替姓名）本來就不會被遮，這是正常的。 |
| 找不到輸出的檔案 | 它就在**原檔案的同一個資料夾**，檔名是原檔名後面多了 02。按「開啟輸出資料夾」最快。 |
| 姓名欄有兩欄（例如「姓名」和「家長姓名」） | 程式優先選標題**剛好等於「姓名」**的那一欄。 |

## 五、隱私聲明

- 本程式**完全離線**：不連網路、不上傳、不回傳任何資料。
- 只會讀取你指定的 Excel 檔，並在**同一個資料夾**寫出一個新檔。
- 原始檔案**不會被修改**（程式會另存新檔）。
- 程式內附的示範資料全部是**虛構人名**，沒有任何真實學生個資。

## 六、給維護者（非必讀）

```
apps/name-masker/
├── app.py                 GUI 入口 ＋ CLI（--selftest / --version / 檔案路徑）
├── mask_names.py          核心：mask_file(path) -> dict，遮罩規則與原始版本完全一致
├── sample_data.py         合成測試資料（零真實個資）
├── make_icon.py           用 PIL 產生 icon.ico / icon.png
├── build.spec             PyInstaller（Windows: onefile exe／macOS: .app）
├── requirements.txt
├── selftest/              合成示範檔
└── README_使用說明.md
```

自我測試（無需 GUI，成功會印 `SELFTEST OK` 且回傳碼 0）：
```
python app.py --selftest
dist\NameMasker.exe --selftest
```
因為打包成視窗程式（console=False），測試結果也會寫到暫存資料夾的
`NameMasker_selftest.log`，並以回傳碼表示成功與否。

自動化情境下若不想跳出訊息框，設定環境變數 `NAMEMASKER_NO_DIALOG=1`。

打包：
```
pip install -r requirements.txt
python make_icon.py
pyinstaller build.spec
```
