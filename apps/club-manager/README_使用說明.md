# 仰望社團管理系統（ClubManager）使用說明

這是一支「雙擊就能用」的小程式，把仰望社團管理系統整套網頁裝在裡面。
**不需要網路、不需要安裝 Python、不需要帳號密碼。**

---

## 一、怎麼開始用

1. 把 `ClubManager.exe` 放在桌面（或任何您找得到的資料夾）。
2. **連按兩下**它。
3. 電腦會跳出一個小視窗「仰望社團管理系統」，同時自動打開您平常用的瀏覽器（Edge、Chrome 都可以），裡面就是社團管理系統。
4. 之後就在**瀏覽器**裡操作：建社團、點名、記經費⋯⋯

> 小視窗裡的四個按鈕：
>
> - **開啟系統（總版）**：不小心把瀏覽器分頁關掉時，按這個重新打開。
> - **開啟各校版清單**：九所學校各自的專屬版本，點學校名字就進去。
> - **開啟備份資料夾**：打開桌面上的 `ClubManager_備份` 資料夾，備份檔請存在這裡。
> - **關閉（停止系統）**：用完按這個。

### 用完要記得關

那個小視窗**就是系統的開關**。關掉小視窗（按「關閉」或右上角的 ×），系統就停了，
這時候瀏覽器的分頁會變成打不開——這是正常的，再雙擊 exe 就會回來。
**瀏覽器分頁關掉不等於系統關掉**，兩個是分開的。

---

## 二、我的資料存在哪裡？（這段最重要）

**資料存在「這台電腦的這個瀏覽器」裡面**，術語叫 localStorage。

也就是說：

- 資料**不在** `ClubManager.exe` 這個檔案裡。複製這支 exe 給別人，對方看到的是空的系統。
- 資料**不會**上傳到網路，也沒有任何伺服器在外面存您的名單。
- 換一個瀏覽器（本來用 Edge 改用 Chrome）、用無痕視窗、或按了瀏覽器的「清除瀏覽資料」，
  都會看不到原本的資料。

### 所以請養成一個習慣

**每次用完，在系統裡按一次「匯出備份」**，把下載下來的 `.json` 檔存到桌面的
`ClubManager_備份` 資料夾（小視窗上的「開啟備份資料夾」按鈕會幫您打開它）。

> ⚠️ 備份的 `.json` 檔裡面有整班學生姓名。
> 請存學校配發的隨身碟或校內雲端，**不要放個人雲端、不要用 LINE 或 email 傳**。

## 三、換電腦、重灌、電腦要送修，怎麼把資料搬走？

### 方法 A：備份匯出／匯入（建議）

1. **舊電腦**：打開系統 →「備份與還原」→ 按「**匯出備份**」→ 得到一個 `.json` 檔。
2. 把這個 `.json` 檔存到隨身碟。
3. **新電腦**：把 `ClubManager.exe` 複製過去 → 雙擊打開 → 「備份與還原」→ 按「**匯入備份**」
   → 選剛才那個 `.json` 檔 → 資料就回來了。

### 方法 B：隨身版 HTML

系統裡有一個按鈕「**下載隨身版 HTML（含目前資料）**」，
按了會下載一個 `.html` 檔，**資料直接寫在那個檔案裡**。
把它存進隨身碟，插到任何一台電腦上用瀏覽器打開，就能看到資料，不用裝任何程式。
（適合臨時到別的教室、借別人電腦看一下的情況。）

### 電腦要送修、要還、要借人之前

1. 先按「**匯出備份**」把 `.json` 存好。
2. 再按系統裡的「**清除全部資料**」。
   **光刪掉 exe 沒有用**——名單存在瀏覽器裡，不會跟著檔案一起消失。

## 四、第一次打開時，Windows 跳出藍色警告怎麼辦？

Windows 看到「沒有付錢買數位簽章的程式」都會先擋一下，這叫 SmartScreen，不是中毒。

畫面會寫「Windows 已保護您的電腦」：

1. 點藍色字「**其他資訊**」。
2. 下面會出現「**仍要執行**」按鈕，按下去。

之後這台電腦就不會再問了。

### macOS 版本（ClubManager.app）

第一次打開若出現「無法打開，因為來自未識別的開發者」：

1. 在 `ClubManager.app` 上按**右鍵** →「**打開**」。
2. 跳出的對話框再按一次「**打開**」。

（或到「系統設定 →隱私權與安全性」，找到剛才被擋下的項目，按「**仍要打開**」。）

## 五、常見問題

**Q：小視窗上出現黃色警告，說埠改成 8766 了。**

系統在您的電腦上開了一個只有自己看得到的小網站，門牌號碼固定是 **8765**。
如果有別的程式先占用了 8765，本程式會自動改用 8766、8767⋯⋯

**問題是：瀏覽器把不同門牌當成不同網站，所以您在 8765 存的資料，在 8766 看不到。**

處理方式（照順序試）：

1. 先確認是不是**已經有一個 ClubManager 在跑**——看工作列上有沒有另一個小視窗。
   有的話，把多開的關掉，用原本那個就好。
2. 重新開機，再雙擊一次 exe，通常就會回到 8765。
3. 如果之前不小心在 8766 存了資料，先在 8766 的那一份按「匯出備份」，
   回到 8765 之後再「匯入備份」，資料就合回來了。

**Q：我點了兩次 exe，會不會開出兩套系統？**

不會。程式會先檢查 8765 上是不是已經有自己在跑；如果有，它只會幫您把瀏覽器打開，
不會再開第二套（不然資料會分家）。

**Q：瀏覽器打不開，網址顯示「無法連上這個網站」。**

代表控制小視窗已經被關掉了（系統停了）。再雙擊一次 `ClubManager.exe` 就好。

**Q：可以給同事用嗎？資料會一起看到嗎？**

exe 可以複製給同事，但**資料不會跟著走**，每台電腦各自獨立。
要把資料給同事，請用上面的「匯出備份 → 對方匯入備份」。

**Q：這個程式會連網路嗎？**

不會。它只在您自己的電腦內部（127.0.0.1，也就是「本機」）開一個小網站，
別台電腦連不進來，資料也不會傳出去。

## 六、給維護者的技術備註

- 執行期**零外部套件**，只用 Python 內建的 `http.server` / `tkinter` / `webbrowser`。
- `web/` 底下的 `index.html`、`schools/`（九校版＋清單）、`docs/`
  是從 `yangwang-club-manager` 專案**原封不動**複製過來的（逐檔 SHA-256 比對一致），
  打包進 PyInstaller 的 `datas`，執行期用 `sys._MEIPASS` 定位。
- 伺服器只綁 `127.0.0.1`、只接受本機來源、拒絕跳出 `web/` 之外的路徑、
  HTML 一律送 `Content-Type: text/html; charset=utf-8`。
- 重複啟動偵測端點：`GET /__clubmanager_ping` → `200 ClubManager OK`。
- 自我測試：`ClubManager.exe --selftest`（不開 GUI、不開瀏覽器；結果同時寫到
  暫存資料夾的 `ClubManager_selftest.log`，回傳碼 0 代表成功）。
- 測試用環境變數：`CLUBMANAGER_NO_BROWSER=1`（不自動開瀏覽器、不跳對話框）。
- 重新產生圖示：`python make_icon.py`（需要 Pillow，只有打包時用得到）。
- 重新打包：`pyinstaller build.spec`。
