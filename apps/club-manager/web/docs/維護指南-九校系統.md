# 九校仰望科學社團管理系統・維護指南

> 給游豐兆老師（與他的 AI）看的。要改任何一所學校的系統，先讀這份，照「改法食譜」動手。
> 最後更新：2026-08-16｜對應版本：`index.html` 約 1,455 行、81 KB

---

## 零、最重要的一條規矩

**永遠只改 `index.html`，改完跑產生器；絕對不要直接編輯 `schools/` 底下的九個檔案。**

```
index.html  ←── 唯一真相來源（你改這裡）
    │
    │  python tools/make_schools.py
    ▼
schools/01-北昌.html … schools/09-西寶.html  ←── 自動產生，改了會被蓋掉
schools/index.html（選校頁）                 ←── 也是自動產生
```

直接改 `schools/` 底下的檔案，下次任何人跑產生器就全部消失。

## 三、資料存在哪（出問題時先看這段）

系統有三層儲存，各管各的：

| 層 | 存什麼 | 存在哪 | 會不會跟著檔案走 |
|---|---|---|---|
| **1. localStorage** | 全部表單資料（名單、點名、規劃、回饋、核銷…） | 瀏覽器，依「網頁位置」隔離 | ❌ 不會 |
| **2. `#bootState` 內嵌節點** | 同上，每次自動存檔時同步寫進 HTML 本身 | HTML 檔案裡面 | ✅ **會**（這是隨身碟能用的關鍵） |
| **3. IndexedDB** | 文件繳交追蹤上傳的檔案（每項上限 50） | 瀏覽器，資料庫名 `yw-files-{STORE_KEY}` | ❌ 不會 |

**開檔還原邏輯**（`load()`）：先讀 localStorage；該位置沒有資料時，才從 `#bootState` 還原並落地。
→ 既有資料永遠優先，不會被舊快照蓋掉；按「清除全部資料」後重開也不會還魂。

**老師的正確用法**：填完 → 「備份與設定」→「下載隨身版 HTML（含目前資料）」→ 存隨身碟 → 以後雙擊那個檔。
（用 Ctrl+S 也行，但存檔類型必須選「**網頁，完整**」。）

## 四、改法食譜（照著做，每則都含驗收）

改完一律走 **§五 的三步流程**（產生 → 測試 → 推送）。

### 食譜 1：新增一所學校

1. 開 `tools/make_schools.py`，在 `SCHOOLS` 清單**最後面**加一行校名全稱。
2. 開 `index.html`，找 `var SCHOOLS = [`（約 342 行），在同樣位置加同一個校名。
   *（這個清單是總覽「學校」下拉選單用的，兩處要一致。）*
3. 跑產生器 → 測試 → 推送。

驗收：`schools/` 多出新檔案；選校頁多一列；新檔打開後總覽的學校欄已預填。

### 食譜 2：改某校校名（例如錯字）

1. `tools/make_schools.py` 與 `index.html` 的 `SCHOOLS` **兩處都改**，位置（第幾個）不要動。
2. 刪掉 `schools/` 底下該校的舊檔（檔名含舊校名那個）。
3. 跑產生器 → 測試 → 推送。

> 校名改了但位置沒動 → STORE_KEY 不變 → 老師既有資料仍在。

### 食譜 3：增減經費核銷科目

- 位置：`index.html` 搜 `var EXP_CATS`（約 368 行）。
- 直接改陣列即可，下拉選單與下方累計統計卡會自動跟著變。
- 目前是：材料費、鐘點費、導師費、餐費、教學演示費、指導出席費、交通費、住宿費。

驗收：核銷分頁下拉出現新科目；登記一筆後統計卡有該科目累計。

### 食譜 4：改學生回饋單的四道題目

- 位置：`index.html` 搜 `var FBQ`（約 361 行），格式為 `["代號","題目文字","對應官方項目"]`。
- **代號 `q1`–`q4` 不要動**（會對不上既有備份與百分比計算）。
- 改完，列印的空白回饋單、統計表、Word 報告都會自動跟著改。

驗收：回饋單分頁題目已換；按「列印空白回饋單」印出來也是新題目。

### 食譜 5：增減「文件繳交追蹤」的項目

- 位置：`index.html` 搜 `var DOCS`（約 347 行），格式為 `["代號","顯示名稱","備註提示"]`。
- 加一項就會自動多一列，含檔案上傳欄與狀態下拉。
- **代號不要跟舊的重複或改名**；`final` 這個代號綁著「列印成果報告書（Word）」按鈕，不要改。

驗收：總覽多出該列；上傳一個檔案後計數正常。

### 食譜 6：改材料費算法或教師人數規則

- 教師人數：搜 `function teacherCount()`（約 389 行）。目前讀「總覽基本資料實填的指導老師數」，未填時暫以 2 位計。
- 顯示文字：搜 `授課教師` 可找到日誌摘要、簽到表、日誌列印、對帳表頭等處。
- 公式文字（（上課人數＋實際授課教師人數）×主題×250 元）：搜 `250 元`。

### 食譜 7：改檔案上傳的數量上限

- 位置：搜 `var UP_MAX = 50;`（約 582 行），改數字即可。提示文字搜 `最多 50` 一併改。

### 食譜 8：改成果報告書 Word 的內容或章節

- 位置：`function buildReportHtml(att, imgRefs)`（約 1044 行）。
- 目前章節：封面／壹基本資料／貳課程規劃表／參課程紀錄（含上傳照片）／肆效益七項％／伍結論（回饋第 5 題）／陸附件一名單、二出席表、三回饋統計、四經費一覽、五起各項上傳檔案。
- 這是 **MHT 格式的 `.doc`**（HTML＋圖片部件組成），Word 可直接開。改動時整段都是字串拼接，注意跳脫。

### 食譜 9：改配色或版面

- 位置：`index.html` 最上方 `:root{ … }`（約 12 行）的 CSS 變數。
- 主要變數：`--paper` 底色、`--ink` 文字、`--ok` 綠、`--no` 紅、`--warn` 黃、`--info` 藍、`--bw` 框寬、`--sh` 陰影位移。
- 視覺語言是「厚框積木」：平塗色塊、3px 黑框、零模糊硬影、按下去沉進影子。

### 食譜 10：改預設週數（目前 24 週）

- 位置：`function blankState()`（約 370 行）的 `for (var i=1;i<=24;i++)`。
- 老師端本來就能在總覽改「總週數」（1–60），除非要改**預設值**，否則不用動程式。

## 五、標準三步流程（每次改完都要做）

### 第 1 步：產生九校版

```bash
cd D:/02-aitt_claude_agent/yangwang-club-manager
python tools/make_schools.py
```

應該印出 9 行 `OK …` 加一行選校頁。

### 第 2 步：本機測試（至少測到你改的那一塊）

用瀏覽器打開 `schools/01-花蓮縣立北昌國民小學.html`，跑這份最小檢查表：

- [ ] 總覽：學校欄已預填校名；七個百分比卡片正常
- [ ] 學生名單：貼 3 行「座號 Tab 班級 Tab 姓名」→ 匯入筆數正確
- [ ] 教室日誌：進第 1 週預設全到；改一人缺席，材料費份數正確
- [ ] 學生回饋單：填回收份數與人數，百分比算得出來
- [ ] 經費核銷：登記一筆，對帳表有反應
- [ ] 備份與設定：按「下載隨身版 HTML」→ 打開下載的檔 → **資料還在**
- [ ] 改動的那一項本身（照該食譜的驗收）

### 第 3 步：推送上線

```bash
git add -A
git commit -m "（改了什麼、為什麼）"
git push origin main
```

GitHub Pages 約 1–3 分鐘後生效。用**無痕視窗**開線上網址確認新內容（一般視窗會吃快取）。

## 六、常見狀況排除

| 症狀 | 原因與處理 |
|---|---|
| 改了卻沒效果 | 十之八九是改到 `schools/` 底下的檔。改 `index.html` 再跑產生器 |
| 線上還是舊的 | Pages 還在部署，或瀏覽器快取。等 3 分鐘＋無痕視窗 |
| 老師說「資料不見了」 | 先問：是不是換了檔案／換了電腦？請他用當初的隨身版檔案開，或用 .json 匯入備份 |
| 老師說「上傳的照片不見了」 | 附件存在該電腦瀏覽器（IndexedDB），**不跟著檔案走**。照片請在同一台電腦上傳並產出 Word 報告 |
| 匯入備份失敗 | 系統會自動先下載「匯入前自動備份.json」，且失敗時原資料不動。檢查該檔是不是本系統匯出的格式 |
| 座號 01 在 Excel 變成 1 | 這是 Excel 行為。改用「列印學生名單」出 A4，或匯入 CSV 時把座號欄設為文字 |

## 七、不要動的東西（動了會壞）

1. `#bootState` 那個 `<script type="application/json">` 節點——拿掉隨身碟功能就死了。
2. `save()` 裡把資料寫進 `#bootState` 的那兩行。
3. `load()` 的優先順序（先 localStorage、後 bootState）。
4. `logSelWired` 這個變數（用 JS 變數而非 DOM 屬性守門，是因為 Ctrl+S 快照會把 DOM 屬性一起存走）。
5. `STORE_KEY` 的命名規則與各校編號順序。
6. 回饋單代號 `q1`–`q4`、文件代號 `final`。

---

## 八、零外部資源原則

整個系統**不引用任何外部檔案**：沒有 CDN、沒有外部字型、沒有外部 JS、沒有框架。
老師雙擊就開、沒有網路也能跑。加任何 `https://` 開頭的 `src`／`href="…css"` 之前，先停下來想清楚。
（連結到外部網站當「延伸閱讀」可以，那不是資源載入。）
