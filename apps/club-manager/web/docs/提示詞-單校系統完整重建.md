# 提示詞：用 Antigravity 從零做出一所學校的仰望科學社團管理系統

> 這份的用途：把下面那一整段**複製貼給 Antigravity**（或 ChatGPT／Claude），
> 它會做出一個功能與 `03-仰望系統-9校專屬版\01-花蓮縣立北昌國民小學.html` 一樣的單一 HTML 檔，
> 並存到你指定的路徑（例如桌面）。

---

## 使用方式（三步）

1. 打開 Antigravity 桌面版。
2. 複製下面 `====` 之間的**整段文字**貼進去。
3. 貼進去之前，先把最前面那兩個空格填掉：
   - **學校全稱**（例：花蓮縣立北昌國民小學）
   - **要存到哪裡**（例：`C:\Users\你的帳號\Desktop`）

跑完它會告訴你檔案存在哪裡。雙擊打開，就是可以用的系統。

> **只是想要現成檔案？** 不必請 AI 重做——直接下載就好：
> <https://rlirdo.github.io/yangwang-club-manager/schools/> 點你的學校 →
> 到「備份與設定」按「下載隨身版 HTML」存到桌面。
> 這份提示詞是給「想自己做一次／想改成自己要的樣子」的人用的。

## 提示詞本體（以下整段複製）

```
====================== 從這裡開始複製 ======================

請幫我做一個「仰望科學社團管理系統」，做成單一 HTML 檔案。

【我的基本資料】
・學校全稱：＿＿＿＿＿＿＿＿＿（例：花蓮縣立北昌國民小學）
・請把做好的檔案存到：＿＿＿＿＿＿＿＿＿（例：C:\Users\我的帳號\Desktop）
・檔名請用：仰望科學社團管理系統_（我的學校全稱）.html

【最重要的三條規矩】
1. 單一 HTML 檔，HTML／CSS／JavaScript 全部寫在同一個檔案裡。
2. 零外部資源：不准引用任何 CDN、外部字型、外部圖片、外部 JS、任何框架或套件。
   老師要能雙擊打開、沒有網路也能用。
3. 全部介面用繁體中文、台灣用語（軟體不是軟件、資料不是數據、預設不是默認）。
   使用者是不太會電腦的國中小老師，用詞要白話。

【這個系統要做什麼】
給參加「財團法人仰望教育基金會・國中小科學社團扶助計畫」的老師，
把一整年社團的名單、出席、回饋、核銷管起來，期末直接生出成果報告書要的東西。

────────────────────────────────
一、版面骨架
────────────────────────────────
最上面固定一條頂欄（深色底、白字），左邊寫系統名稱與「財團法人仰望教育基金會 × 國立東華大學」，
右邊放三個即時統計方塊：社團學生（人數）、累計出席率（%）、已上課週數。
再右邊顯示「已自動存檔 時:分:秒」。

頂欄下面一排分頁按鈕，共七個，順序固定：
總覽｜學生名單｜課程規劃表｜教室日誌｜學生回饋單｜經費核銷｜備份與設定
點哪個就顯示哪一頁的內容（同一頁面切換，不是換檔案）。

視覺風格：淺米白底（#faf7f0）、白色卡片、3px 純黑外框、右下方 6px 純黑硬陰影（不要模糊陰影），
按鈕按下去會往右下沉進陰影裡。字體大一點（內文 17px），因為讀者裡有老花眼的老師。
表格用白底細線，不要跟按鈕一樣厚框。

────────────────────────────────
二、七個分頁各要有什麼
────────────────────────────────

【分頁 1：總覽】
(1) 基本資料列：學校（下拉，預設就選我上面填的那一所，另有「其他」可自填）、社團名稱、
    指導老師兩格、學年度（預設 115）、總週數（數字，預設 24，可改 1～60）。
    下面小字提醒：「核銷實務（學校主計室會看的地方）：官方範本以 24 週編排，實際週次依各校；
    每週通常至少 2 小時。社團人數、年級範圍送件前以基金會窗口為準。」
(2) 「效益達成情形（成果報告書・肆）— 七個百分比」儀表板，七張大卡片：
    ① 學生對科學探索的興趣提升（來源：回饋單第 1 題）
    ② 學生上課專心、能參與討論（回饋單第 2 題）
    ③ 學生能自己完成實驗操作（回饋單第 3 題）
    ④ 學生能向別人說明實驗（回饋單第 4 題）
    ⑤ 社團整體出席率（教室日誌自動算）
    ⑥ 課程延伸應用到正式自然課（老師自己填）
    ⑦ 老師覺得對專業有實質幫助（老師自己填）
    每張卡顯示大數字百分比與來源說明；沒資料時顯示「—」。⑥⑦ 下面各給一個輸入框讓老師填。
    旁邊放一顆按鈕「列印成果報告書素材頁」（見第五節）。
(3) 「文件繳交追蹤（期末結案要交的東西）」表格，欄位四個：
    結案文件｜檔案上傳｜狀態｜備註／提示
    共 12 列：課程規劃表（貳）、學生名單（附件一）、單元教案、社團課簽到表（附件二）、
    學生回饋單（附件三）、課程紀錄（參）、觀課紀錄表、專家聯絡單、專家教學演示紀錄表、
    教授訪視觀課指導紀錄表、校內核銷各類表格、成果報告書。
    ・「檔案上傳」欄：每一列都能上傳檔案，每列最多 50 個。已上傳的列出檔名與大小，
      可以點檔名下載、也可以刪除，並顯示「共 N／50 個」。
    ・「狀態」欄：下拉選單（未開始／進行中／✔ 已完成）。
    ・「成果報告書」那一列，在名稱下方多一顆按鈕「列印成果報告書（Word）」（見第六節）。
(4) 最下面一塊「三個核銷地雷」提醒：
    ① 同一張請購單，2026 年 9–12 月和 2027 年 1–6 月要分開填。
    ② 鐘點費認列「實際上課日期」，不是請購日期。
    ③ 材料費認列「發票上的日期」；份數要和教室日誌「出席學生數＋實際授課教師人數」相符。

【分頁 2：學生名單】
(1) 一個大的貼上框，老師從 Excel 整批複製學生貼進來，按「貼上匯入」就進系統。
    解析規則（很重要，請照做）：
    ・一行一位學生。先用 Tab、逗號、全形逗號、頓號切；切完只有一段時，才改用空白切。
    ・第一個非空白列如果含有「座號／學號／編號／班級／姓名／名字／備註」這些字，
      就當成 Excel 的標題列整列略過，並在訊息裡講明「第 1 列看起來像標題列，已略過」。
    ・用空白切的那條路：開頭是純數字就當座號；接著若某段以「班」結尾就當班級；
      **剩下的全部併回姓名**（例如「01 Yosi Takun」要變成 座號 01、姓名「Yosi Takun」，
      不可以把 Yosi 當成班級）。
    ・重複的（同班級同姓名）跳過，訊息要說略過幾位。
(2) 名單表格：座號、班級、姓名、備註都可以直接在格子裡改，每列有刪除鈕。
(3) 按鈕：＋手動加一位、列印學生名單（附件一）、匯出名單 CSV。

【分頁 3：課程規劃表】
(1) 表格欄位：週次｜日期｜課程內容｜時數｜任課教師｜備註。列數＝總覽設定的總週數。
    時數預設 2，可以改（可填 0.5 的倍數）。所有格子直接編輯、即時存檔。
(2) 按鈕：列印課程規劃表、列印時數表（鐘點費核銷用）、匯出 CSV。
    ・時數表：只列有日期或有點名的週次，每列顯示該週實填時數，頁尾合計是加總（不可以寫死 2）。

【分頁 4：教室日誌】
(1) 上方：週次下拉（1～總週數）、該週日期與主題（自動從課程規劃表帶）、
    「全到」按鈕、「清除本週」按鈕、列印空白簽到表、列印本週日誌、匯出出席 CSV。
(2) **進到某一週時預設全部學生「出席」**，老師只要把沒來的改掉。
    每位學生一顆按鈕，點一下循環切換：出席 → 缺席 → 請假。
(3) 摘要列（點名表上方）顯示：
    「本週出席 N 人／共 M 人（缺席 x、請假 y）　→　加上授課教師 T 位＝材料費 (N+T) 份」
    ・T ＝ 基本資料裡實際填了幾位指導老師（填 1 位就是 1、填 2 位就是 2）；
      兩位都沒填時暫以 2 位計，並在摘要下方紅字提醒「請先到總覽基本資料填指導老師姓名」。
    ・如果有人還沒被點到（部分點名），摘要要多一行紅字：
      「還有 N 位未點名，這週的數字先不算數」。
(4) 同一頁下方再一塊「本週課程紀錄（成果報告書・參 的素材）」：
    一個多行文字框（文字說明）＋照片檔名欄＋圖說欄，逐週各自儲存。
    一顆按鈕「列印課程紀錄（參）」，把有填的週次整理成一張表印出來。
(5) 出席率算法（重要）：出席率 ＝ 出席人數 ÷ 總報名人數，**請假與缺席都算進分母**，
    只累計「有點名過」的週次。

【分頁 5：學生回饋單】
(1) 「回收份數（實際收回的份數）」輸入框，旁邊自動顯示「應收 N 份（名單人數自動帶入）｜回收 x 份／應收 N 份」。
(2) 四道題目的統計表，每題四個選項各填人數，最右邊自動算「達成率」：
    達成率 ＝（很同意＋同意）÷ 回收份數。
    四道題目文字固定用這四句（一題對一個官方百分比）：
    1. 參加社團以後，我更想知道科學的「為什麼」
    2. 上課的時候，我會專心聽，也會跟大家一起討論
    3. 做實驗的時候，我會照安全規則做，可以自己完成，或老師稍微提醒一下就能完成
    4. 我可以跟別人說明我們的實驗在做什麼，或介紹我做出來的成果
    選項固定四個：很同意／同意／普通／不同意。
(3) 勾稽提醒（三種狀態，不要一律報錯）：
    ・某題四個選項合計 > 回收份數 → 紅字「合計 X ＞ 回收 Y，請檢查（是不是把人次當成人數了？）」，
      該題達成率顯示「—」。
    ・合計 < 回收份數且大於 0 → 灰字「尚未填完（合計 X／Y）」，達成率照樣算給參考。
    ・剛好相等 → 不顯示任何訊息。
(4) 一顆按鈕「列印空白回饋單（發給學生）」：印出 A4 紙本問卷，含班級／座號欄、
    四題選擇題（四個方框讓學生勾）、第 5 題開放題「這學期我最喜歡的一堂課是＿＿，因為＿＿」。
(5) 最下面一個多行文字框：「第 5 題（開放作答）彙整」，給老師抄學生寫的內容，
    期末寫「伍、結論與建議」直接取材。

【分頁 6：經費核銷】
(1) 抬頭紅字（一字不要改）：
    「身分證字號、戶籍住址、匯款帳號——這三樣不貼進任何 AI，也不放雲端，只在學校的紙本表上寫。
      AI 幫你算的是時數、份數、金額，不碰身分資料。」
(2) 登記列：類別下拉（材料費、鐘點費、導師費、餐費、教學演示費、指導出席費、交通費、住宿費）、
    認列日期、品項說明、金額、份數、對應週次（下拉含「整學期／未指定」與第 1～N 週）、登記按鈕、匯出 CSV。
(3) 已登記表格：類別、認列日期、期別、品項、金額、份數、週次、刪除鈕。
    期別自動判斷：2026-09～2026-12 顯示「上期（9–12 月）」；2027-01～2027-06 顯示「下期（1–6 月）」；
    其他顯示「⚠ 期別外」。
    上方八個科目各一張累計金額卡。
(4) 「材料費對帳」表：逐週比對「出席＋實際授課教師人數」與該週登記的材料費份數，
    相符顯示 ✔、不符顯示差幾份。若有「整學期／未指定」的登記，
    多出一列把它們加總，跟全期合計比對；此時各週改顯示「含在整學期登記（見下方全期合計）」。
    表格上方寫明：核算公式（上課人數＋實際授課教師人數）× 主題 × 250 元；
    並註明「材料費、餐費、茶水費的發票／收據，需開立基金會統編：82339563 財團法人仰望教育基金會」。

【分頁 7：備份與設定】
四顆按鈕與說明：
(1) 「下載隨身版 HTML（含目前資料）」← 最重要，見第四節。
(2) 「匯出備份（.json）」：把全部資料存成一個 json 檔，檔名含校名與日期。
(3) 「匯入備份」：選一個 json 檔還原。規則：
    ・匯入前先自動下載一份「匯入前自動備份.json」（救命用）。
    ・先補齊欄位、畫面渲染成功才真正落地；失敗就原資料完全不動，並告訴使用者匯入已取消。
(4) 「載入示範資料」、「清除全部資料」（要兩次確認）。
文字提醒要寫：
    ・.json 備份裡有整班學生姓名——存學校配發的碟或校內雲端，不要放個人雲端、不要用 LINE 或 email 傳。
    ・電腦要送修、要還、要借人之前：先按「匯出備份」把 .json 存好，再按「清除全部資料」。
      光把 HTML 檔刪掉沒用——名單存在瀏覽器裡，不會跟著檔案走。

────────────────────────────────
三、資料怎麼存（照這個做，不然老師會弄丟資料）
────────────────────────────────
1. 用瀏覽器的 localStorage 存全部表單資料，鍵值用一個固定字串（例如 yw-club-mgr-北昌）。
   任何欄位一改就自動存，並更新頂欄的「已自動存檔 時:分:秒」。
2. **同時**在 HTML 裡放一個內嵌資料節點：
   <script type="application/json" id="bootState">null</script>
   每次自動存檔時，把整包資料 JSON 也寫進這個節點的內容（記得把 < 換成 \u003c 避免壞掉）。
3. 開檔時的還原順序：
   先讀 localStorage；**這個位置沒有資料時**，才去讀 #bootState 的內容還原，並立刻存進 localStorage。
   → 已經在用的資料永遠優先，不會被舊快照蓋掉；按「清除全部資料」後重開也不可以還魂。
4. 為什麼要這樣：老師會把檔案存到隨身碟、帶去別台電腦。localStorage 不會跟著檔案走，
   內嵌節點會。這是這個系統能「帶著走」的關鍵，請務必實作。
5. 注意：不要用 DOM 元素屬性（例如 dataset）當「已初始化」的旗標，
   因為 Ctrl+S 存下來的快照會把屬性一起存走，重開後判斷會失準。請用 JavaScript 變數。

────────────────────────────────
四、「下載隨身版 HTML」按鈕
────────────────────────────────
按下去要：
1. 先執行一次存檔，確保 #bootState 是最新資料。
2. 取整個頁面的 HTML（"<!DOCTYPE html>\n" + document.documentElement.outerHTML），
   做成 Blob 下載，檔名例如「仰望社團系統_學校名_20260819.html」。
3. 老師把這個檔存到隨身碟，換一台電腦雙擊打開，全部資料都還在。
按鈕旁邊寫一句：「用 Ctrl+S 也可以，但存檔類型要選『網頁，完整』。」

────────────────────────────────
五、列印功能（用瀏覽器列印，不要外部套件）
────────────────────────────────
做法：準備一個平常隱藏的 #printArea，按列印鈕時把要印的 HTML 塞進去再呼叫 window.print()；
用 @media print 讓列印時只顯示 #printArea。每張列印頁的頁首都要有：學校名、社團名、學年度。

要有這幾顆列印按鈕：
1. 課程規劃表（含時數欄，頁尾寫「共 N 週」）
2. 授課時數表（鐘點費核銷用，逐列實填時數、頁尾合計、下方留承辦人／主任／校長簽名欄）
3. 空白簽到表（座號、班級、姓名、出席✓、簽名欄；頁尾寫「本週出席＿人／共 N 人　加上授課教師 T 位＝材料費＿份」）
4. 本週教室日誌（已點名結果）
5. 空白學生回饋單（發給學生的紙本）
6. 學生名單（附件一）
7. 課程紀錄（參）
8. 成果報告書素材頁：一張 A4，上半是壹的基本資料（含兩位指導老師），
   下半是七個百分比，每個數字後面帶來源與分母，例如「③ 82%（回收 17 份：很同意 8＋同意 6）」、
   「⑤ 91%（已點名 12 週）」；若有回饋單第 5 題彙整，一併印出當「伍」的素材。

六、「列印成果報告書（Word）」按鈕

做法：組一份 MHT（multipart/related）文字：第一個部件是 base64 過的 HTML（Content-Location: report.htm），

報告內容照官方《115 學年度國中小科學社團扶助計畫 成果報告書》的架構：

  二、學生作品或成果發表）
```
