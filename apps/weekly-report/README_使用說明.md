# 週報產生器（WeeklyReportMaker）使用說明

東華大學自然資源與環境學系　仿生與環境工作坊　個人週報（碩士生標準版）

這支小程式幫你把「這一週做了什麼」變成一份可以直接上台報告的 PowerPoint：
自然科學雜誌風的版面、每一頁都寫好逐字稿（PowerPoint 的備忘稿），十一到十五頁。
**不用安裝 Python，也不用連網路**，雙擊就能用。

---

## 一、第一次打開

### Windows

1. 把 `WeeklyReportMaker.exe` 放在任何一個你找得到的資料夾（例如「桌面」）。
2. 雙擊它。
3. 第一次打開時，Windows 可能跳出藍色視窗「**Windows 已保護您的電腦**」（SmartScreen）。
   這是因為這支程式沒有花錢買微軟的簽章，不是有病毒。
   請按視窗裡的「**其他資訊**」，再按下面出現的「**仍要執行**」。
   之後再打開就不會再問了。
4. 如果公司或學校的防毒軟體擋下來，請把這個檔案加入白名單，或改用學校電腦上的本機帳號執行。

### macOS

1. 把 `WeeklyReportMaker.app` 拖進「應用程式」資料夾。
2. **第一次請不要用雙擊**：在圖示上按**右鍵 → 打開**，再按一次「**打開**」。
   （直接雙擊會出現「無法打開，因為無法驗證開發者」，那是 Gatekeeper 的預設保護。）
3. 之後就可以正常雙擊了。

## 二、每週的固定流程（大約十五分鐘）

1. **打開程式**，上面那一排先填好：報告人、年級、指導教授、報告日期。
   按「**依報告日期帶入本週期間**」，程式會自動算出這一週的星期日到星期六。
2. **一個分頁填一個區塊**。預設是五塊：壹 論文、貳 實驗、參 修課、肆 專案、伍 行政。
   - 區塊**名稱可以改**（例如把「專案」改成「科普列車」），但**中文序號（壹貳參肆伍）是規格，不能改**。
   - 區塊數可以在上面調成 3 到 6 塊。
   - 「本週進度」**一行寫一件事**，不用加項目符號，程式會自己加。
   - **這一塊這週沒有進度就留空白**——程式會自動在總覽頁寫上「本週無進度」，而且**不會把那一塊刪掉**。這是老師看週報時掃的第一件事。
   - 每一塊最多放 2 張照片：按「選擇…」挑檔案，然後把**圖說、拍攝日期、地點**填上（這是 APA 圖說規矩，也是老師會問的第一句話）。
3. 最後一個分頁填「**問題與請益**」和「**下週計畫**」，一樣一行一件事。
   - 沒有問題就留空白，程式會寫「本週沒有需要老師裁示的問題」——**這一頁不可以省略**。
   - 下週計畫裡只要句子出現「硬性、截止、期限、小考、考試」，那一列就會自動標成硬性時程。
4. 按「**儲存內容…**」把表單存成一個 `.json` 檔（例如 `週報內容.json`）。
   **下一週打開程式後按「載入內容…」**，把上週的內容叫回來改，五分鐘就填完。
5. 按「**產生週報**」。檔案會存到畫面上那個「輸出資料夾」（預設是桌面的「週報產生器_輸出」），
   檔名是 `20260913_你的名字_週報.pptx`。
6. 程式會**自動跑一次驗收**並跳出結果表。全部顯示「通過」就可以交了。
7. 按「**開啟輸出資料夾**」把檔案拿出來，用 PowerPoint 打開。
   上台前請先看一次「**檢視 → 備忘稿**」，那裡就是每一頁的逐字稿，可以照著唸。

> 想先看看成品長什麼樣子？按「**填入示範內容**」，程式會填入一份虛構的示範（報告人「林小仿」），
> 直接按「產生週報」就會產生一份範例檔。這份示範資料全部是編的，不是任何真實的人或數據。

## 三、「驗收」按鈕在檢查什麼

按「驗收 .pptx…」可以挑**任何一份** PowerPoint 週報來檢查（不一定要這支程式做的），會逐項顯示：

| 項目 | 為什麼要查 |
| --- | --- |
| 中文序號（壹貳參…） | 區塊序號是規格，不可以改成 1. 2. 3. |
| 「本週無進度」原文 | 沒進度的區塊要原文寫這五個字，一字不差 |
| 總覽頁列出全部區塊 | 沒進度的那一塊也要在總覽頁上 |
| 「問題與請益」頁 | 必備頁，沒有問題也要寫出來 |
| 「下週計畫」頁 | 必備頁 |
| 每一頁都有備忘稿逐字稿 | 規格裡唯一寫成「必辦」的一條 |
| （附帶）頁數 11–15 頁 | 碩士生版的基本盤 |
| （附帶）每頁標題 ≥ 30pt | 老花眼也要看得清楚 |

## 四、常見狀況

| 狀況 | 怎麼辦 |
| --- | --- |
| 雙擊沒反應，等幾秒才開 | 正常。第一次啟動要把程式解壓到暫存資料夾，大約三到十秒。 |
| SmartScreen 藍色視窗 | 「其他資訊」→「仍要執行」。見上面第一節。 |
| macOS 說「無法驗證開發者」 | 右鍵 → 打開 → 再按「打開」。 |
| 按「產生週報」說找不到照片 | 照片被搬走或改名了。程式不會因此中斷，那一格會變成灰色「照片佔位」，補上照片再產一次即可。 |
| 產生的檔案打不開 | 確認電腦有 PowerPoint 或 WPS；也可以上傳到 Google 簡報開啟（但備忘稿的字型會變）。 |
| 中文變成方框 | 這台電腦沒有「微軟正黑體」。Windows 一定有；macOS 會自動改用蘋方（PingFang）。 |
| 想換一台電腦用 | 把 `.exe` 和你的 `週報內容.json` 一起複製過去就好，不用安裝任何東西。 |
| 逐字稿想自己改 | 直接在 PowerPoint 的備忘稿欄位改，改完存檔即可；下次重新產生會覆蓋，記得先另存。 |

## 五、給會寫程式的人（可以跳過）

```
python app.py                # 開 GUI
python app.py --selftest     # 不開視窗，用內建合成資料跑完整流程＋六項驗收，成功印 SELFTEST OK 並回傳 0
python app.py --version      # 版本
pyinstaller build.spec       # 打包成 dist/WeeklyReportMaker.exe（Windows）或 .app（macOS）
python make_icon.py          # 重新產生 icon.png / icon.ico
```

- 相依套件：`pip install -r requirements.txt`（python-pptx、Pillow、lxml；GUI 用內建的 tkinter）。
- `core.py` 是版式積木（色票、頁面骨架、表格、流程圖、照片框、備忘稿），
  `report_builder.py` 是內容組裝與逐字稿，`validator.py` 是六項驗收。
- 打包後 `--selftest` 仍會印字（接上呼叫端的主控台），並把記錄寫到
  暫存資料夾的 `WeeklyReportMaker_selftest.log`，**回傳碼 0 = 成功、1 = 失敗**。
- 不打包任何字型檔（微軟正黑體有授權限制），只把字型**名稱**寫進 pptx。
- `selftest/sample_data.json` 是合成資料，**不含任何真實個資**。
