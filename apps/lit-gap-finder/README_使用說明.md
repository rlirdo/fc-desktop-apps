# FC文獻缺口搜尋工具 FC LitGap Finder 1.0.0 — 使用說明

> 東華大學自然資源與環境學系　仿生與環境工作坊
> 適用：Windows（`FC文獻缺口搜尋工具.exe`，CI 產物名 `FCLitGapFinder.exe`）；macOS 版（`FCLitGapFinder.app`）為實驗性質
> 製作：NDHU自資系游豐兆製作

用多組關鍵字到**開放書目資料庫**找文獻，依可勾選的**合格指標**篩選，
算出關鍵字組合之間的**研究缺口**，再一次匯出 **APA 7 參考文獻（Word／PDF）**、Excel 清單、
缺口矩陣、趨勢圖、RIS／BibTeX 與查詢紀錄。

---

## 一、使用三步驟

### 步驟 1　檢索（① 檢索頁）

1. 在「關鍵字組」每一行輸入一組關鍵字，**同義詞用「;」分隔**，可以中英混列（最多 6 組）：
   ```
   serpentine; 蛇紋石
   deep sea water; 深層海水
   far infrared; 遠紅外線
   ```
   也可以直接貼 DOI（例如 `10.1038/s41467-019-10189-x`），程式會用 DOI 取回該篇。
2. 設定出版年起迄（預設 2016–今年）、語言、每組上限（預設 50 筆）、存檔資料夾。
3. 選「檢索方式」：
   - **各組分別檢索（聯集）**（預設）：每一組各查一次再合併，適合先把各主題的文獻抓齊。
   - **所有組同時符合（交集）**：組內同義詞 OR、組間 AND，適合找交集文獻。
4. 按〔開始檢索〕。進度視窗會顯示目前步驟，可隨時按〔取消〕或主畫面的〔停止〕；
   已取得的結果會保留。

### 步驟 2　指標與缺口（② 指標與缺口頁）

1. 勾選要用的合格指標（說明見下節），按〔套用指標〕。
   - 「全部保留但標示」：未通過的文獻以紅字顯示，仍可勾選納入。
   - 「只保留全部通過」：結果表只顯示全部通過的文獻（手動加入的中文文獻一律顯示）。
2. 回到① 按〔缺口矩陣〕：程式查詢每兩組、每三組關鍵字在 OpenAlex 同時出現的篇數，
   **少於門檻（預設 5 篇）標為「缺口」**（紅字）。點選任一列可看該組合的前 10 篇。
   下方折線是近 10 年每年篇數。

### 步驟 3　整理與匯出（③ 結果頁）

- **納入**欄點一下切換 ☑／☐；〔全選〕〔全不選〕。
- **章節**欄點一下出現下拉選單（1 緒論／2.1 文獻回顧／2.2／3 方法／4 結果／5 討論／附錄／未分類；可在〔設定〕自訂）。
- **拖曳**任一列可調整順序；點欄位標題可排序（再點一次反向）。
- 雙擊一列開啟 DOI 頁面；右鍵可「開 OA 全文」、改章節、移到最上／最下。
- 右側即時顯示該筆的 **APA 7 格式**、文內引用與各指標判定理由。
- 〔手動加入中文文獻〕：中文文獻不自動檢索，請自行填寫作者、年、題名、刊名、卷期頁（DOI 選填）。
- 「參考文獻順序」：**APA 規則**（先中文依筆畫、後英文依字母）或**自訂**（照結果表拖曳後的順序）；
  勾「匯出依章節分組」則依章節標籤分段。
- 〔匯出全部〕會在存檔資料夾下建立 `文獻缺口_<關鍵字>_<YYYYMMDD>\`，內含：

| 檔案 | 內容 |
| --- | --- |
| `參考文獻_APA7.docx` | APA 7 參考文獻（懸掛縮排、12 pt Times New Roman／標楷體）；附錄「指標證據表」「檢索策略」 |
| `參考文獻_APA7.pdf` | 同上的 PDF（有 Word 用 Word 轉檔，否則以標楷體自行排版） |
| `文獻清單與指標.xlsx` | 全部欄位＋各指標判定與理由 |
| `缺口矩陣.xlsx` | 兩兩／三三組合篇數、缺口標示、各組合前 10 篇、年度趨勢 |
| `趨勢圖.png` | 近 10 年每年篇數折線＋前 10 高被引長條 |
| `references.ris`／`references.bib` | 匯入 EndNote、Zotero、Mendeley 用 |
| `查詢紀錄.json` | 檢索條件、時間、各檔案匯出結果（可重現檢索） |

- 〔下載 OA 全文〕：只下載**合法開放取用**的 PDF（Unpaywall `best_oa_location.url_for_pdf` 或 OpenAlex OA 連結），
  存在 `OA全文\<年>_<第一作者>_<短題>.pdf`，來源網址、授權與下載時間記在 `OA下載紀錄.csv`。
  非 OA 文獻只提供 DOI 連結，**不會嘗試任何付費或非法來源**。

## 二、指標說明

| 代號 | 指標 | 判定方式 |
| --- | --- | --- |
| ① | 有 DOI 且可解析 | 有 DOI，且向 doi.org 送出 HEAD 請求可導向出版社頁面 |
| ② | 有合法 OA 電子全文 | Unpaywall／OpenAlex 回報有開放取用版本（gold／green／hybrid／bronze） |
| ③ | 文獻類型符合 | 預設只收期刊論文；可另勾會議論文、專書章節 |
| ⑥ | 出版年範圍 | 預設 2016–今年；勾「含經典（不限年）」則不限 |
| ⑦ | 期刊有 ISSN 且在 DOAJ 或主要出版社 | 判斷不了時標「?　待人工確認」，**不算不通過** |
| ⑩ | 語言 | 英文／中文／不限 |
| ⑫ | 相關性分數 | 標題命中 ×3 ＋ 摘要命中 ×1 ＋ log(1＋被引次數) ＋ 年份近度；權重可在② 頁滑桿或〔設定〕調整。只用來排序，不淘汰文獻 |

「指標摘要」欄依序顯示 ①②③⑥⑦⑩ 的結果：✔ 通過、✘ 未通過、? 待人工確認。

## 三、Unpaywall email 說明

- Unpaywall、Crossref、OpenAlex 這些免費 API 要求使用者在請求中附上一個聯絡 email（稱為 polite pool），
  方便資料庫在流量異常時聯絡，**不會寄信給你，也不需要註冊或密碼**。
- 預設值為 `811554006@gms.ndhu.edu.tw`，可在① 頁或〔設定〕改成自己的 email。
- 設定存在 `%APPDATA%\FCLitGap\config.json`，**不儲存任何密碼**；
  email 只會出現在匯出的 `查詢紀錄.json` 的 `mailto` 欄位，其他輸出檔都不含 email。

## 四、限制與注意事項

1. **書目以資料庫回傳為準**：Crossref／OpenAlex 偶有作者名、大小寫、頁碼錯誤，送出論文前請逐筆核對（雙擊可開 DOI 頁）。
2. **不杜撰書目**：每一筆 API 文獻都保留原始回傳 JSON 於快取；手動加入者標 `source=manual`，
   匯出時註明「使用者自填，未經 API 驗證」。
3. **不用 Google Scholar、不爬網頁**；中文期刊（華藝、臺灣期刊論文索引）請手動加入。
4. 缺口矩陣的篇數是 OpenAlex 全文檢索的命中數，屬「粗估」；篇數少代表值得深入確認，不等於一定沒人做過。
5. Semantic Scholar 免金鑰限速（每秒 1 次），失敗時自動略過，不影響其他結果。
6. 同一查詢 7 天內使用快取（`%APPDATA%\FCLitGap\cache.sqlite`），可在〔設定〕→〔清除快取〕。
7. 網路中斷或某個資料庫失敗時會跳出提示，**已取得的結果照常顯示與匯出**。
8. Windows SmartScreen 會擋未簽章程式：點「其他資訊」→「仍要執行」。

## 五、命令列（給助教與自動化）

```
FC文獻缺口搜尋工具.exe --selftest              離線自我測試（樣本→指標→缺口→匯出全部格式→隱私檢查→視窗稽核）
FC文獻缺口搜尋工具.exe --check-privacy 資料夾   檢查輸出資料夾不含 email 以外個資（不給資料夾＝用樣本匯出後檢查）
FC文獻缺口搜尋工具.exe --version
```

自我測試結果寫在 `%TEMP%\FCLitGapFinder_selftest.log`，成功 exit 0、失敗 exit 1。

開發者：`python app.py`（需 `pip install -r requirements.txt`）；封裝 `pyinstaller --noconfirm build.spec`；
GUI 自動化截圖 `python selftest/gui_shots.py`（存到 `selftest\shots\`）。
