# 客語語音小幫手 HakkaVoiceHelper 1.0.1 使用說明

給幼兒園客語老師用的三步驟小工具。原則：**畫面與草稿交給工具，客語用字與定稿由老師負責**（AI 生成，教師審核）。

| 分頁 | 做什麼 | 要不要網路 |
|---|---|---|
| ① 華語變客語文字 | 把華語放進剪貼簿、開官方翻譯網頁，由老師本人翻譯後貼回 | 要（用瀏覽器開官方網頁） |
| ② 客語文字變語音 mp3 | 客語漢字 → 客語語音 mp3＋來源說明檔 | 要（公開語音合成示範服務） |
| ③ 客語語音變文字（試用） | 音檔 → 文字，只能抓大意 | 不用（在這台電腦離線辨識） |

## 第一次執行

1. 雙擊 `HakkaVoiceHelper.exe`。Windows 若跳出「Windows 已保護您的電腦」，點「其他資訊」→「仍要執行」（本程式沒有購買程式碼簽章）。
2. 要用分頁 ③，請把講師給的 `models` 資料夾放在 exe 旁邊，變成：
   ```
   HakkaVoiceHelper.exe
   models\hakka-whisper-ct2-int8\model.bin（約 0.8 GB）…
   ```
   也可以放在 `%LOCALAPPDATA%\HakkaVoiceHelper\models\hakka-whisper-ct2-int8\`，或在分頁 ③ 按「選擇模型資料夾…」指定。本程式不會自動下載模型。

## 步驟 ① 華語變客語文字（輔助交接）

1. 在「華語句子」輸入要說的話（右邊會顯示字數；超過 100 字會提醒分段）。
2. 按其中一顆按鈕：
   - 「複製並開啟：客委會即時翻譯」（建議）
   - 「複製並開啟：長問翻譯器」
   - 「複製並開啟：Gohakka」（需登入，免費每日 20 字）
3. 瀏覽器開啟官方網頁後，**由老師本人**貼上（Ctrl+V）、按翻譯、複製客語漢字。
4. 回到小幫手按「貼上客語漢字（從剪貼簿）」，檢查用字。也可以直接打客語漢字。
5. （建議）官方翻譯網頁在客語漢字旁邊也有**拼音**：一併複製，回來按「貼上官方拼音（從剪貼簿）」，貼進「官方拼音（選填，貼上後可自動檢查語音有沒有唸錯）」框。
6. 按「下一步：變成語音 →」（官方拼音會一起帶到分頁 ②，在那裡也可以修改）。

> 本工具**不會**用程式連線、爬取或自動操作這三個網站，只幫您把文字放進剪貼簿並開啟網頁。客語的用字、文法與句法以官方工具結果為準。

## 步驟 ② 客語文字變語音 mp3

1. 確認「客語漢字」（可直接修改）。
2. 選腔調（四縣、海陸、大埔、饒平、詔安、南四縣；預設四縣）、語者（清單在開啟時從服務取得，可按「重新整理」）、語速（0.5–1.5，**越大越慢**）。
3. 輸出資料夾預設是「桌面\客語語音」，檔名預設取客語文字前 12 字；同名會自動加序號，不會覆蓋。
4. 按「產生客語語音 mp3」。程式依句號、問號、驚嘆號、換行切句，一句一句送出（每句約 5–10 秒）。可按右下「取消」。
5. 完成後畫面會顯示斷詞、客語拼音、【與官方拼音比對】與檔案位置；按「播放」或「開啟資料夾」。
6. 同一個資料夾會多一個 `<檔名>_來源說明.txt`：記錄華語原句、客語漢字、斷詞、拼音、官方拼音、與官方拼音比對結果、腔調、語者、語速、翻譯來源、語音來源與授權、產生時間。

### 與官方拼音比對（1.0.1 新增）

有貼官方拼音時，工具會自動比對「語音實際唸的拼音」和「官方拼音」：
- **音節比對（所有腔調）**：只比字母。全部一致會顯示「✓ N 個音節全部一致」；有不同會用紅字列出，例如「第 6 字『著』：官方 zogˋ／語音 do31」，並提醒「這幾個字語音可能唸錯。建議這一句改用客委會語音合成網頁產生。」，同時出現「改用客委會語音合成網頁」按鈕。
- **聲調提示（只有四縣腔）**：音節相同但聲調不同時，列為「聲調不同（提示）」，僅供參考（四縣對照：ˊ=24、ˇ=11、ˋ=31、無符號=55；入聲 b、d、g 結尾：ˋ=2、無符號=5）。其他腔調只比音節，不比聲調。
- 漢字數和兩邊音節數一樣時，會對回是第幾個字；對不上時只列音節位置，請人工核對。
- 沒貼官方拼音：顯示「沒有貼官方拼音，無法自動檢查；請老師聽一遍確認」。
- 比對只是提醒，不會修改文字或語音。實測例：「落雨吔，記得著水衣。」的「著」，官方 zogˋ、語音唸成 do31（多音字讀錯）。

**請注意**
- 文字會送到公開的語音合成示範服務，**請勿輸入幼兒姓名或任何個資**。
- 這是大家共用的服務，請勿大量連續使用；單次最多 1,200 字。
- 給孩子聽的請由老師親口唸；本音檔供老師備課練習與家長參考。
- 如果連不上或服務在休眠，畫面會出現「改用客委會語音合成網頁」按鈕（會複製客語漢字並開啟官方網頁）。

## 步驟 ③ 客語語音變文字（試用）

1. 按「選擇音檔…」（mp3／wav／m4a／aac／ogg／flac）。
2. 按「開始辨識」：第一次會先載入模型（約十幾秒），之後文字會一段一段出現。
3. 在結果框校對後，按「複製文字」或「另存 .txt」。

**老實說明**：在這台電腦上離線辨識，音檔不會上傳。結果是**華語為主的繁體中文**，**只能抓大意、常會聽錯**，請對照原音校對。短句、發音清楚、教材式的句子比較準。實測例：
- 「恁早啊，細兔仔愛去學校上課。」→「早安，小兔子愛去學校上課」（大意對，開頭有時會重複「早安早安」）。
- 「食飯愛正經食，正毋會食到半出半入」→「食飯愛認真吃炸魚會十到半出半入」（較長、較文的句子錯很多）。

需要正式的客語辨識，請按「開啟客委會語音辨識網頁（官方，建議）」。

## 三個網站的使用規定（2026/11/13 查證）

- **客委會「臺灣客語語音資料庫」**（speech.hakka.gov.tw）：翻譯、語音合成、語音辨識 API 要先申請核准（政府機關、學校、公益法人可申請，每次三個月，僅限非營利，不得轉授權或提供第三方）。網站本身：非會員每次 100 字、線上即時翻譯每日 1,000 字。
- **Gohakka**（gohakka.org）：免費會員翻譯每日 20 字（需登入）；API 只在 Enterprise 方案；內容 CC BY-SA 4.0；使用其語音合成結果須註明「語音來源：GoHakka.org」；不得擷取平台資源訓練 AI 模型。
- **長問翻譯器**（translate.bronci.com.tw）：Beta，翻譯內容由 AI 產生；沒有公開 API。

## 常見問題

- **按了「產生」很久沒反應？** 公開示範服務若在休眠，第一次喚醒可能要一兩分鐘；每句最多等 120 秒，失敗會自動重試一次。
- **語者清單是空的？** 代表連不上語音合成服務；檢查網路後按「重新整理」，或改用客委會語音合成網頁。
- **分頁 ③ 說找不到模型？** 請向講師索取 `models` 資料夾，放在 exe 旁邊（見「第一次執行」）。
- **客語漢字裡有字顯示成方框 □？** 有些客語用字（例如「𫣆」）這台電腦的字型沒有，畫面會顯示成方框，工具也會提示「有些客語用字（第 N 個字）這台電腦可能顯示成方框□：字還在，不影響語音與存檔」。字其實還在，語音、mp3 與來源說明檔都正常。想正常顯示，可安裝全字庫正楷體／正宋體（CNS11643 全字庫，國發會提供）。
- **辨識沒有出現任何文字？** 畫面會顯示「沒有辨識出文字。這段錄音可能太短、太小聲，或模型聽不懂；請改用客委會語音辨識網頁。」
- **辨識結果跟原音不一樣？** 這是試用功能，結果只能抓大意，請一定要校對。
- **可以拿來做商業用途嗎？** 不行。合成與辨識模型都是 CC BY-NC 4.0（非商業）。

## 命令列（講師／自動測試用）

```
HakkaVoiceHelper.exe --version
HakkaVoiceHelper.exe --selftest            離線自我測試，結果寫 selftest\selftest.log
HakkaVoiceHelper.exe --selftest-online     實際合成一句「恁早。」
HakkaVoiceHelper.exe --tts "恁早啊，細兔仔愛去學校上課。" --accent sixian --speed 1 --out 範例.mp3
HakkaVoiceHelper.exe --tts "落雨吔，記得著水衣。" --official-pinyin "log iˋ eˊ, gi dedˋ zogˋ suiˋ iˊ." --out 比對.mp3
HakkaVoiceHelper.exe --asr 音檔.wav --model models\hakka-whisper-ct2-int8 --out 結果.txt
HakkaVoiceHelper.exe --shots 截圖資料夾    以示範資料產生教學截圖（不連網、不跑模型）
```

`--official-pinyin` 會印出與官方拼音的比對結果（有音節不同時 exit code 仍為 0，只是提醒）。`--speaker` 可給語者編號（例如 `3`）或介面上的標籤。命令列結果也會寫在 exe 旁的 `selftest\` 資料夾。
