# selftest／合成測試資料

這個資料夾放的是**自我測試**用的東西，裡面**沒有任何真實學生資料**。

- `make_sample_input.py`：產生上一層 `sample_input\` 裡三個合成的 xlsx，
  格式刻意複刻「姓名遮罩與學生編號」（NameMasker 2.0）處理過的樣子：
  * A 欄「學生編號」（`115-1_EC_1`…）
  * 學號欄全部是 `OOOOOOOOO`
  * 姓名欄已遮罩（王小明 → 王O明）
  * 自由文字裡的同學姓名已換成學生編號
  * 另附一張工作表「學生編號連結姓名」（再識別鑰匙）
    —— 專門用來測試本程式**必須忽略它**
  姓名、學號、作答內容全部虛構（例如「王小明」「賴恩」）。
  需要重新產生時執行：`python selftest\make_sample_input.py`
- 測試資料本體放在 `..\sample_input\`（同時也是 GUI「跑示範」用的資料，
  所以只保留一份，打包時會一起帶進 exe）。
- `樣本_選課名單_合成.pdf`（2.1）：模仿東華教務系統「選課名單」版面的
  **合成** PDF，6 位虛構學生（甲小明…己淑芬，學號 9900000xx），
  用來做 `core/roster.py` 的**端對端** PDF 名單解析測試。
  它也會被 `build.spec` 打包進 exe，所以 exe 的 `--selftest` 一樣測得到。
  （原始 docx 與產生腳本不留在 repo；這份 PDF 是一次性做好的固定樣本。
  如果哪天檔案不見了，`--selftest` 會自動略過端對端那一段，
  只測「抽字後的行列表」解析，其餘檢查照跑。）

## 自我測試在測什麼

`python app.py --selftest`（或 `HomeworkWordCloud.exe --selftest`）會：

1. 用 `sample_input\` 的合成資料跑完整流程到系統暫存資料夾；
2. 檢查簡報頁數 **＝ 3（封面／總覽／結尾）＋ 題數（＋附錄概念矩陣頁）**；
3. 檢查每一題都有 `Q0N_concept_matrix.csv` 與 `Q0N_questions.csv`；
4. 檢查每個覆蓋率都介於 **0–1**，而且至少有一題抓到 3 個重點；
5. 檢查版面幾何 **出界 0、重疊 0**；
6. 檢查文字雲 PNG **至少 3 張**；
7. 檢查**每一頁都有備忘稿逐字稿**；
8. 跑隱私檢查（名冊姓名＋9 碼學號＋email 樣式），必須 **0 命中**；
9. 額外確認「學生編號連結姓名」工作表的內容**完全沒有進到輸出**；
10. 額外跑一次**向下相容檢查**：臨時合成一份「原始 Zuvio 匯出」格式
    （學號是 int、姓名沒遮罩、自由文字含同學姓名），確認程式會自己
    補學生編號、把學號改成全 O、把姓名換成編號。
11. **2.1 名單流程檢查**（全部用合成資料，臨時寫在系統暫存資料夾）：
    * PDF 行解析三種抽字排法都讀得出來（欄位黏在一起／空白分隔／逐行分開），
      而且表頭與頁尾雜訊行 **0 誤判**；
    * 端對端讀 `樣本_選課名單_合成.pdf` → 6 人、編號對得上序號；
    * Excel 名單**有序號** → 依序號編號；**無序號** → 依學號字串遞增排序；
    * 兩個原始 Zuvio 合成檔（作答順序刻意不同）→ 同一位同學**兩題同一個編號**；
    * 名單外的作答者（退選）在兩個檔案都是 **`_101`**，而且**回寫對照表**
      （含「首次出現檔案」）；
    * **全班人數＝名單人數**；附錄概念矩陣依編號數字排序；
    * **沒有名單就被擋下**（訊息要說得出要先給名單）、`--no-roster` 放行；
    * 隱私檢查（含比對對照表裡**所有真實姓名與學號**）**0 命中**。

全部通過就印 `SELFTEST OK` 並回傳 0，任何一項失敗回傳 1。

詳細紀錄會另外寫到系統暫存資料夾的 `HomeworkWordCloud_selftest.log`
（在 Windows 上就是 `%TEMP%\HomeworkWordCloud_selftest.log`）。
