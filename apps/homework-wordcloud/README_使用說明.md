# 學生作業文字雲（HomeworkWordCloud）使用說明

把 Zuvio 老師端下載的作業檔，變成一份可以直接上台講的「同學作答分析」簡報，
每一題配一張文字雲，姓名全部自動遮罩。**不用安裝 Python，雙擊就能用。**

- 適用：Windows 10／11（`HomeworkWordCloud.exe`）、macOS（`HomeworkWordCloud.app`）
- 需要網路嗎：**完全不用**。整個過程都在你自己的電腦裡跑，沒有任何資料會上傳。

---

## 一、第一次打開（放行安全提示）

程式是自己做的、沒有花錢買微軟／蘋果的簽章，所以系統第一次會出來擋一下。這是正常的。

**Windows：出現藍色視窗「Windows 已保護您的電腦」**
1. 點視窗裡的小字 **「其他資訊」**。
2. 按 **「仍要執行」**。
3. 之後再打開就不會再問了。

**macOS：出現「無法打開，因為無法驗證開發者」**
1. 在 `HomeworkWordCloud.app` 上按 **右鍵 →「打開」**（不要用雙擊）。
2. 跳出的視窗再按一次 **「打開」**。
3. 如果還是被擋：**系統設定 → 隱私權與安全性 → 最下面「仍要打開」**。

> 防毒軟體偶爾也會多看兩眼（自製程式常見）。如果被隔離，把它加入信任清單即可。

## 二、畫面上的東西是什麼

| 欄位／按鈕 | 說明 |
|---|---|
| 課程名稱、教師、教學助理 | 會印在簡報封面上，填一次就會被記住 |
| 學期起日 | **第 1 週的那個星期日**，格式 `2026-09-06`。按「跑本週」時靠它算現在是第幾週 |
| 輸入資料夾 | 放 Zuvio 下載的 `.xlsx`（或通用 `.csv`）的資料夾 |
| 輸出資料夾 | 簡報跟文字雲要存到哪裡，預設是桌面的 `HomeworkWordCloud_輸出` |
| **跑示範** | 用程式內建的**假資料**跑一次，看看輸出長什麼樣子（第一次用建議先按這個） |
| **跑本週** | 依「學期起日」自動判斷第幾週，處理輸入資料夾裡的檔案 |
| **跑指定週次** | 右邊填數字（例如 `3`），補做或重做某一週 |
| **隱私檢查** | 挑一個輸出資料夾來掃，確認裡面**沒有**任何學生的原始姓名（要 0 命中） |
| **開啟輸出資料夾** | 直接打開輸出資料夾 |
| 順便輸出縮圖 | 需要電腦裝有 PowerPoint；只是方便你快速翻頁檢查，不打勾也完全不影響簡報 |
| 執行紀錄 | 下面那塊黑白文字區，會即時顯示跑到哪一步。跑的時候按鈕會變灰，這是正常的 |

## 三、每週日的固定流程（SOP）

1. **下載作業**：到 Zuvio 老師端 →「下載數據」→ 把下載到的 `.xlsx` 全部放進**輸入資料夾**。
   （一份 xlsx = 一題；檔案放幾份就會分析幾題。）
2. **打開程式**，確認上面的課程資訊與「學期起日」沒錯。
3. 按 **「跑本週」**，等執行紀錄出現 `完成！輸出資料夾：…`（大約 10～60 秒）。
4. 按 **「隱私檢查」**，選剛剛那個輸出資料夾（例如 `W3-0920-0926`），
   確認紀錄最後一行是 **`[通過] 0 命中`**。
5. 按 **「開啟輸出資料夾」**，拿走 `同學作答分析-第N周.pptx`。
   - 每一頁的**備忘稿都有逐字稿**，可以照著念。
   - 想改字就直接在 PowerPoint 裡改，不影響下次執行。

輸出資料夾裡還會有：

| 檔案 | 內容 |
|---|---|
| `同學作答分析-第N周.pptx` | 主要成品：封面＋總覽＋每題一頁（文字雲＋重點詞）＋結尾 |
| `summary.md` | 文字版摘要：各題作答率、全班 TOP10 關鍵詞、同學的疑問 |
| `wc\Q0N_wc.png` | 各題文字雲圖檔（想貼到別的地方可以直接拿） |
| `Q0N_*.csv`、`analysis.json` | 分析用的中間資料，**姓名都已遮罩** |
| `qa\` | 版面自動檢查報告（＋縮圖，如果有勾） |

## 四、隱私鐵律（請務必遵守）

1. **輸出的姓名一律遮罩**：第 2 個字改成 O（王小明 → 王O明；賴恩 → 賴O）。
   連同學寫在答案裡的名字也會一起換掉，程式做完會自己檢查一次。
2. **原始 xlsx 只留在你自己的電腦**，不要放雲端共用資料夾、不要傳給別人、不要上傳網路。
3. **交出去之前一定先按「隱私檢查」**，要看到 `[通過] 0 命中` 才算數。
   如果出現 `[不通過]`，請**先不要**把檔案交出去，把執行紀錄整段回報。
4. 程式全程離線，不會傳送任何資料。

## 五、常見狀況

**「輸入資料夾裡沒有任何 .xlsx 或 .csv」**
→ 檔案還沒放進去，或選錯資料夾。Zuvio 下載下來如果是壓縮檔，記得先解壓縮。
→ 也不要放 `~$` 開頭的暫存檔（那是 Excel 開著沒關產生的，關掉 Excel 就會消失）。

**「學期起日是空的，無法自動判週」**
→ 填第 1 週的那個星期日（例如 `2026-09-06`），或直接用「跑指定週次」填數字。

**文字雲的中文變成一堆方框或空白**
→ 代表電腦上找不到中文字型。Windows 請確認 `C:\Windows\Fonts\msjh.ttc`（微軟正黑體）還在；
macOS 請確認 `/System/Library/Fonts/PingFang.ttc`。真的沒有的話，
安裝 Google Fonts 的 **Noto Sans TC** 後重跑即可。（程式不會偷偷內建字型，避免授權問題。）

**沒有產生縮圖**
→ 縮圖要靠 PowerPoint 幫忙轉檔。沒裝 PowerPoint、或用 macOS，就會自動跳過，
**不影響簡報本身**，紀錄會寫「略過」。

**某一題沒有文字雲**
→ 那題的有效詞太少（預設少於 5 個詞），或那題是選擇題（選項文字全班都一樣，
做成文字雲沒意義）。該頁會改用純排版呈現。

**視窗卡住不動？**
→ 跑大批資料時按鈕會變灰、畫面看起來沒反應是正常的，請等執行紀錄繼續往下捲。

**想確認程式本身有沒有壞掉**
→ 按「跑示範」。它用內建的假資料跑完整流程，能跑完就代表程式沒問題，問題出在輸入檔。

## 六、給工程師的備註

```bat
HomeworkWordCloud.exe --selftest   :: 無視窗自我測試，成功回傳 0 並印 SELFTEST OK
HomeworkWordCloud.exe --version    :: 版本
```

自我測試會用內建合成資料跑完整流程，驗收「簡報 ≥ 4 頁、文字雲 ≥ 3 張、隱私檢查 0 命中」，
詳細紀錄寫在 `%TEMP%\HomeworkWordCloud_selftest.log`（macOS 在 `$TMPDIR`）。

從原始碼跑與重新打包：

```bat
pip install -r requirements.txt
python app.py --selftest
python make_icon.py
pyinstaller build.spec
```

設定檔記在 `~\.homework_wordcloud\settings.json`（關視窗時自動存），刪掉就會回到預設值。
