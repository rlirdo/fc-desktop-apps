# 學生作業文字雲　HomeworkWordCloud 2.2

把 Zuvio 老師端「下載數據」匯出的 xlsx，變成一份可以直接報告的
**「同學作答分析」簡報**（每頁都有逐字稿）＋每題一張文字雲＋兩份分析表。

**這支程式不連網路、不上傳任何資料，全部在你自己的電腦裡跑完。**

---

## 〇之一、2.2 最重要的改變：六個重點、四類提問

每一題的分析從「**3 個重點、2 類提問**」加深成「**6 個重點、4 類提問**」：

| 項目 | 2.1 | 2.2 |
|---|---|---|
| 每題重點數 | 3 個 | **6 個**（候選不足 6 個時有幾個列幾個） |
| 概念矩陣欄數 | 3 欄＋提到重點數 | **6 欄＋提到重點數** |
| 覆蓋率 | 整體、三個都提到 | 整體（≥1 個）、**提到 ≥3 個**、**六個都提到** |
| 提問分類 | 概念理解類、操作應用類 | **計算數據類、操作應用類、延伸探究類、概念理解類** |
| 題頁版面 | 左文字雲＋右上重點卡＋右下提問卡 | 左文字雲（較窄）＋右上六列重點卡＋**右下 2×2 四張提問小卡** |
| 附錄概念矩陣 | 每頁 3 題 × 3 欄 | **每頁 2 題 × 6 欄（①–⑥）**，最多 3 頁 |

> **已經在用 2.1 的人**：舊的 `settings.json` 存的是 2.1 的預設值，
> 2.2 第一次啟動會自動升級（重點數 3 → 6、兩類提問 → 四類），不用手動改。
> 若你自己把 `top_concepts` 改成別的數字，或自訂了 4 類以上的關鍵詞，程式不會動它。

## 〇、2.1 最重要的改變：先有名單，學生編號才會固定

2.0 的學生編號是「依**每個檔案內**首次出現順序」給的，所以同一位同學
在 Q01 是 `115-1_EC_3`、在 Q02 可能變成 `115-1_EC_7`，
**沒辦法跨題、跨週追蹤**。這是已經確認的缺陷。

2.1 改成：**先拿你手上的原始名單產生一份固定對照表，之後每次都照它給編號。**

```
原始名單（Excel／CSV／東華教務系統的選課名單 PDF）
        │  ← 第一步先做這個（只要做一次，整學期共用）
        ▼
115-1_EC_學生名單與學生編號對照表.xlsx
   工作表「學生編號對照」：序號 | 學生編號 | 學號 | 姓名 | 班級
   工作表「名單外作答者」：學生編號 | 學號 | 姓名 | 首次出現檔案（101 起）
        │
        ▼
Zuvio 匯出的 xlsx ──► 遮罩＋固定學生編號 ──► 分析、文字雲、簡報
```

### 兩種輸入，處理方式不一樣

| 輸入檔 | 要不要名單？ |
|---|---|
| **「姓名遮罩與學生編號」的輸出**（A 欄有「學生編號」） | **不用**，照舊直接跑 |
| **原始 Zuvio 匯出檔**（A 欄沒有「學生編號」） | **一定要**先選名單或對照表 |

沒有選名單就按「跑本週」而輸入又是原始檔時，程式會**擋下來**並告訴你要先選名單。
真的沒有名單時才勾「沒有名單，改依檔案內出現順序編號」
（命令列：`--no-roster`）——這是 2.0 的舊行為，**不建議**。

> **對照表（codebook）含真實姓名與學號，是唯一能還原身分的「再識別鑰匙」。**
> 只能留在自己的電腦，不要上傳雲端、不要放進 git、不要傳給任何人。
> 它和「姓名遮罩與學生編號」（NameMasker 2.1）產生的檔案**格式完全一樣**，
> 兩支程式可以共用同一份。

## 〇之二、原本的兩步流程（仍然建議）

```
Zuvio 下載數據 (xlsx)
        │
        ├─ ① 先用「姓名遮罩與學生編號」（NameMasker 2.1）處理
        │      → 產生「原檔名02.xlsx」：A 欄多了「學生編號」、
        │        學號變成 OOOOOOOOO、姓名變成 王O明、
        │        自由文字裡的同學姓名換成學生編號
        │
        └─ ② 把「原檔名02.xlsx」放進本程式的「輸入資料夾」→ 按「跑本週」
```

1. **第一步（另一支程式）**：打開「姓名遮罩與學生編號」，填課程縮寫（例 `EC`）與學期
   （例 `115-1`），載入名單，把 Zuvio 匯出的 xlsx 丟進去，它會另存一個 `…02.xlsx`。
2. **第二步（本程式）**：把那個 `…02.xlsx` 放進「輸入資料夾」，按「跑本週」。

> **絕對不要**把 `…02.xlsx` 裡的「學生編號連結姓名」工作表（＝再識別鑰匙）
> 傳給任何人、上傳雲端或放進 git。那張表只能留在你自己的電腦。
> 本程式解析時會**自動跳過**那張表，不會讀入裡面任何姓名。

**一步也可以**：直接把原始 Zuvio 匯出檔放進輸入資料夾，
本程式會用同一套規則補上學生編號、把學號改成 O、把姓名遮罩——
但**前提是先選好名單或對照表**（見上一節）。

## 〇之三、名單檔長什麼樣子

### A. Excel／CSV 名單
任一工作表的**前 5 列**裡有一列同時出現「學號」與「姓名」就讀得到；
欄位順序不拘，空白的表頭格也沒關係。可以另有「序號」「班級／系級／系所」「電子郵件」。

| 序號 | 學號 | 姓名 | 班級 |
|---|---|---|---|
| 1 | 990000001 | 甲小明 | 自資系大三 |
| 2 | 990000002 | 乙小華 | 自資系大三 |

（表格裡的學號與姓名都是**虛構範例**。）

常見來源：e 學苑匯出的名單（學號｜班級｜姓名｜電子郵件…）、自己做的點名冊。

### B. 東華教務系統「選課名單」PDF
直接選那份 PDF 就好（**文字型 PDF**，不是掃描影像）。
程式用純 Python 的 `pypdf` 抽字，以「9 碼學號」為錨點，
把姓名／序號／班級判斷出來，`【註*】` 之類的註記與表頭雜訊會自動忽略。
讀不出來時會明確告訴你「這份 PDF 讀不出名單，請改用 Excel 名單（需有 學號、姓名 欄）」。

### C. 編號規則
* 名單**有序號欄**而且是 1..N 不重複 → 學生編號 ＝ `{學期}_{課程縮寫}_{序號}`
* 沒有序號 → 依**學號字串遞增排序**給 1..N
* 學號重複 → 直接報錯，請先把名單整理乾淨
* **不在名單的作答者**（退選、旁聽…）→ 自 `101` 起編號，
  登記在對照表的「名單外作答者」工作表，**跨檔跨週都是同一個編號**

### D. 換課程／名單改版（加退選）怎麼辦
* **換課程**：改「課程縮寫」與「學期」，再選那門課的名單 → 會產生另一個檔名的對照表，
  兩門課互不干擾。程式會記住你上次用的對照表路徑。
* **名單改版（加退選）**：
  * 只是**多了人**：直接重選新名單，勾「**覆寫既有對照表**」重編；
    或不勾、讓新同學以 101 起登記在「名單外作答者」（原有同學編號完全不動）。
  * 想保留舊編號 → **不要勾覆寫**。不勾的時候程式一律沿用既有對照表，
    只會把新出現的人追加到「名單外作答者」。
  * 想整份重編 → 勾「覆寫既有對照表」（命令列 `--overwrite-codebook`）。
    ⚠ 重編之後**舊輸出的編號就對不起來了**，請整學期只做一次。

## 一、第一次使用（3 分鐘）

1. 雙擊 `HomeworkWordCloud.exe`。
   * Windows 可能跳出藍色的「Windows 已保護您的電腦」→ 點 **[其他資訊]** →
     **[仍要執行]**（這是因為程式沒有花錢買數位簽章，不是病毒）。
   * macOS 若說「無法打開，因為無法驗證開發者」→ 在「系統設定 ▸ 隱私權與安全性」
     最下面按 **[仍要打開]**；或在 Finder 對著程式按右鍵 ▸ 打開。
2. 按 **[跑示範]**。它會用內建的**虛構**資料跑一次完整流程，
   在你的桌面產生 `HomeworkWordCloud_輸出\示範\`。打開來看看輸出長什麼樣子。
3. 看懂輸出之後，再換成自己的資料。

## 二、視窗上的欄位

| 欄位 | 說明 |
|---|---|
| 課程名稱／教師／教學助理 | 會印在簡報封面 |
| **課程縮寫** | 2 個英文字母（自動轉大寫），例 `EC`＝環化、`GC`＝普化 |
| **學期** | 例 `115-1`（三位數字 + `-` + 1 或 2） |
| 學期起日 | 第 1 週的**星期日**，例 `2026-09-06`；「跑本週」靠它算第幾週 |
| 輸入資料夾 | 放遮罩後的 xlsx（或原始 Zuvio xlsx／通用 CSV） |
| 輸出資料夾 | 預設是桌面的 `HomeworkWordCloud_輸出` |
| **名單／對照表檔**（2.1 新增） | 原始名單（`.xlsx`／`.csv`／選課名單 `.pdf`）或既有對照表 `.xlsx`；**輸入是原始 Zuvio 檔時必備** |
| **產生／更新對照表**（按鈕） | 只產生對照表、不處理作業；下面那行會顯示「讀到 N 人、編號規則、名單外 m 人」 |
| **開啟對照表**（按鈕） | 用 Excel 打開剛剛產生的對照表確認 |
| **覆寫既有對照表**（勾選） | 名單改版要整份重編時才勾；不勾一律沿用既有對照表 |
| **沒有名單，改依檔案內出現順序編號**（勾選） | 2.0 的舊行為，**不建議**；同一學生在不同檔案編號會不同 |

**學生編號**就長成 `課程縮寫` 與 `學期` 組出來的樣子：`115-1_EC_1`、`115-1_EC_2`…
同一位同學在整份檔案裡永遠是同一個編號，所以你可以追蹤「這位同學這學期的變化」，
卻不會在任何輸出檔裡看到他的姓名或學號。

按鈕：

* **跑示範**：用內建合成資料跑一次（不會碰到你的資料）。
* **跑本週**：依「學期起日」自動算今天是第幾週，輸出到 `Wn-MMDD-MMDD\`。
* **跑指定週次**：右邊填數字，例如補跑第 3 週。
* **隱私檢查**：掃描輸出資料夾，比對名冊姓名、9 碼學號、電子郵件樣式。**必須 0 命中**。
* **開啟輸出資料夾**。

## 三、每週日的固定流程（SOP）

**學期一開始只要做一次**：在「名單／對照表檔」選這門課的名單
（Excel／CSV／選課名單 PDF）→ 按 **[產生／更新對照表]** →
確認顯示「讀到 N 人」→ 按 **[開啟對照表]** 檢查一下。
之後每週都沿用這份對照表，同學的編號整學期不變。

1. **週日晚上**到 Zuvio 老師端，把這一週的每一份作業按「下載數據」存成 xlsx。
2. 把它們全部丟進「姓名遮罩與學生編號」跑一次（課程縮寫／學期／名單填一樣的）。
   （不想跑這一步也行，直接把原始 xlsx 放進輸入資料夾，本程式會自己遮罩。）
3. 把產生的 `…02.xlsx` 複製到輸入資料夾底下的當週子資料夾，例如
   `我的輸入\W3-0920-0926\`（沒有子資料夾也可以，程式會直接讀最外層）。
4. 打開本程式 → 確認「名單／對照表檔」還指著那份對照表 → 按 **[跑本週]** → 等 10–60 秒。
5. 按 **[隱私檢查]** → 確認顯示 **`[通過] 0 命中`**
   （有選對照表時，會一併比對對照表裡**所有真實姓名與學號**）。
6. 打開輸出資料夾裡的 `同學作答分析-第N周.pptx`，
   每一頁的**備忘稿**都已經寫好逐字稿，可以直接照著唸。
7. 原始 xlsx 與「學生編號連結姓名」留在自己電腦，不要外傳。

## 五、名詞解釋（報告時會被問到的幾個詞）

### 1. 六個重點（Top-6 concepts）
程式把全班這一題的回答斷詞之後，算出每個詞**有幾位同學提到**（不是出現幾次），
取前 **6** 名當成「這一題全班真正在講的六件事」。
同分的時候比出現次數，再同分就照字典序，**每次跑結果都一樣**（不會亂跳）。
候選詞不到 6 個時就**有幾個列幾個**（不會補空白，也不會報錯）。
同義詞可以在 `config.json` 的 `synonyms` 裡合併，例如把
「原子經濟性」「原子利用率」都算成「原子經濟」。
想改個數就調 `config.json` 的 `top_concepts`。

### 2. 概念矩陣（concept matrix）
一張**「學生 × 概念」的 0/1 表**（2.2 起是 6 個概念欄）：

| 學生編號 | 廢棄物減量 | 原子經濟 | 綠色溶劑 | 能源效率 | 再生原料 | 可分解 | 提到重點數 |
|---|---|---|---|---|---|---|---|
| 115-1_EC_1 | 1 | 1 | 0 | 1 | 0 | 0 | 3 |
| 115-1_EC_2 | 1 | 0 | 0 | 0 | 0 | 1 | 2 |

`1` 代表這位同學的回答有提到那個概念（或它的同義詞），`0` 代表沒有。
簡報的附錄頁只放**前 10 位**當樣子看（每頁 2 題、最多 3 頁），完整的一列一位同學在
`Q0N_concept_matrix.csv`，可以直接用 Excel 打開排序。

### 3. 覆蓋率（coverage）
* **單一概念覆蓋率** ＝ 提到這個概念的人數 ÷ 作答人數。
* **整體覆蓋率** ＝ 至少提到 6 個重點**其中一個**的人數 ÷ 作答人數。
  這個數字最有用：**低於六成就代表這一題的重點全班沒抓到，下堂課要補講。**
* **提到 ≥3 個重點比例** ＝ 六個重點裡講到 3 個以上的人數 ÷ 作答人數。
  這個數字看「講得夠不夠完整」。
* **六個都提到比例** ＝ 6 個重點全部講到的人數 ÷ 作答人數。通常偏低是正常的。

### 4. 提問分類（question taxonomy）
程式把每則回答切成句子，抓出**提問句**。判定規則刻意「寧缺勿濫」，
符合下面**任何一條**才算提問：

1. 句尾是 **？** 或 **?**
2. 句尾是 **嗎／呢**（可以沒有問號）
3. 句子**開頭**就是疑問詞：為什麼／為何／如何／怎麼／是否／什麼是／哪些／哪個／
   可否／能不能／有沒有…；英文 Why／How／What／Is／Can… 開頭也算

> 句子**中間**有疑問詞但整句是陳述句的**不算**提問。
> 例如「了解物質是由原子組成，以及原子如何組成不同物質」含「如何」，
> 但它是在描述學到什麼，不是在問問題。

抓出來的提問句再用關鍵詞分成**四類**（2.2）。
`config.json` 的 `question_types` 是**保序**的，**寫在前面的類別優先序愈高**：
命中的關鍵詞數一樣多時，排在前面的那一類勝出。

| 順序 | 類別 | 關鍵詞（可在 config.json 的 `question_types` 改） | 老師該怎麼回應 |
|---|---|---|---|
| 1 | **計算數據類** | 怎麼算、計算、公式、單位、數值、濃度、莫耳、pH、平衡常數、幾次方、換算、多少、比例、百分比、有效數字 | 帶一次計算、對一次單位 |
| 2 | **操作應用類** | 怎麼做、如何（做／用／看／觀察／測量）、步驟、方法、實驗、儀器、操作、應用、例子、處理、How | 示範一次、給一個實例 |
| 3 | **延伸探究類** | 未來、影響、如果、會不會、能不能、可否、為什麼不、生活、產業、政策、案例、比較好、替代、永續、環境衝擊、風險 | 開放討論、指一篇延伸閱讀 |
| 4 | **概念理解類** | 為什麼、為何、原理、定義、意義、差別、不同、關係、機制、是什麼、什麼是、何者、哪一項、本質、特性、Why、What | 重講觀念、補一張圖 |

四類都沒中時還有一道**後備規則**：句子裡有「什麼／嗎／為／Why」就歸概念理解類。
再沒中才計入「其他」（目標 ≤ 總提問的兩成），
只在頁面上顯示則數，明細一樣在 `Q0N_questions.csv`。

## 六、簡報長什麼樣子

* **封面**（深藍）→ **總覽**（各題作答率＋整體覆蓋率長條）
  → **一題一頁** → **附錄：概念矩陣（每頁 2 題，最多 3 頁）** → **結尾**
* 題頁版面（2.2 新版，開放文字題）：
  * 左邊（0.55–5.55 吋）：文字雲＋三行圖說（圖 N、來源、週次日期）
  * 右上（5.78–12.78 吋）：**六個重點卡**，一列一個概念
    （①–⑥　概念｜提及 n 人｜覆蓋率 %），底線下一行寫整體覆蓋率／提到 ≥3 個／全部提到
  * 右下：**四張提問小卡 2×2**，每張第一行「類別｜提問數｜提問人數」（14pt），
    第二行代表句（11pt）
  * 最下面：深藍色橫幅，一行寫前三大重點＋「另三個重點見右上表」
* 選擇題／測驗題（回答是選項或「答對／答錯」）不做文字雲，整頁自動換一套版面：
  左邊是作答人數大數字＋各子題最多人選的選項；
  右上改成「各子題選項分佈」（每個子題列出最多人選的前幾個選項與人數、百分比）；
  右下改成「答對率」（測驗題）或「作答完成率」（一般選擇題）。
  總覽頁的「整體覆蓋率」欄對這種題會寫「—（選擇題）」，也不列入平均覆蓋率。
* **全班人數**是整個輸入資料夾共用同一個分母，優先順序是：
  **① 對照表「學生編號對照」的人數**（2.1 起；有選名單／對照表就用它）→
  ② 輸入資料夾裡的名冊檔人數 → ③ 本週所有檔案出現過的不重複學生編號總數。
  不會每題各算各的。
* 附錄的概念矩陣頁，學生一律**依編號數字排序**（`115-1_EC_2` 排在 `115-1_EC_10` 前面）；
  2.2 起每頁放 2 題（6 個概念欄 ①–⑥ × 前 10 位），題數多時自動分頁、**最多 3 頁**，
  其餘請看 `Q0N_concept_matrix.csv`。
* 附錄頁不想要的話，把 `config.json` 的 `appendix_matrix` 改成 `false`。

## 七、進階設定（config.json）

程式會讀 exe 內建的 `config.json` 當範本，你在視窗上改的設定會存到
`使用者資料夾\.homework_wordcloud\settings.json`。要改詞典類的設定，
可以直接編輯這些欄位：

| 欄位 | 用途 |
|---|---|
| `user_words` | 課程專有名詞（讓斷詞不要把「原子經濟性」切開） |
| `stopwords_extra` | 不想進文字雲的廢詞 |
| `keep_short` | 要保留的短詞（`AI`、`pH`、`CO2`…） |
| `synonyms` | `{"原子經濟": ["原子經濟性", "原子利用率"]}` |
| `question_types` | **四類提問**的關鍵詞清單（**順序就是判定優先序**） |
| `top_concepts` | 每題抓幾個重點（**2.2 起預設 6**） |
| `appendix_matrix` | 要不要附錄概念矩陣頁（預設 true） |
| `min_words_for_cloud` | 詞太少就不畫文字雲（預設 5） |
| `config_version` | 設定檔格式版本（2.2）；舊檔會自動升級，不用自己填 |

## 八、命令列用法

```
HomeworkWordCloud.exe --version     印版本（HomeworkWordCloud 2.2.0）
HomeworkWordCloud.exe --selftest    無視窗自我測試，成功回傳 0
HomeworkWordCloud.exe --help        說明

:: 只產生／更新對照表（不處理作業檔）
HomeworkWordCloud.exe --make-codebook-only --roster 名單.pdf ^
        --course EC --semester 115-1 [--overwrite-codebook]

:: 無視窗跑一週
HomeworkWordCloud.exe --run --input <輸入資料夾> --output <輸出資料夾> ^
        [--week 3] [--roster 名單.(xlsx|csv|pdf) | --codebook 對照表.xlsx] ^
        [--no-roster] [--overwrite-codebook] ^
        [--course EC] [--semester 115-1] [--course-name 環境化學] ^
        [--start 2026-09-06] [--thumbs]

:: 隱私檢查（有給對照表就一併比對裡面所有真實姓名與學號）
HomeworkWordCloud.exe --check-privacy <輸出資料夾> ^
        [--input <原始輸入資料夾>] [--codebook 對照表.xlsx]
```

2.1 新增的旗標：

| 旗標 | 用途 |
|---|---|
| `--roster <檔>` | 原始名單（`.xlsx`／`.csv`／選課名單 `.pdf`）→ 產生／沿用對照表 |
| `--codebook <檔>` | 直接用既有的對照表 `.xlsx`（不重編） |
| `--no-roster` | 沒有名單也要跑（2.0 行為，**不建議**） |
| `--overwrite-codebook` | 對照表已存在時整份重編（預設是沿用） |
| `--make-codebook-only` | 只產生對照表，不處理作業檔 |
| `--run` | 無視窗跑一週（配合 `--input`／`--output`／`--week`） |

`--selftest` 會用內建合成資料跑完整流程，並檢查：
簡報頁數＝3＋題數（＋附錄，每頁 2 題最多 3 頁）、每題兩份 CSV 都在、
覆蓋率介於 0–1 且「≥1 個 ≥ ≥3 個 ≥ 全部都提到」、
**每題開放題重點數＝min(6, 候選數)**、**概念矩陣欄數＝1＋重點數＋1**、
**四類提問的分類單元測試**（每類至少 3 個問句＋陳述句干擾，「其他」≤20%）、
版面出界 0／重疊 0、每頁都有備忘稿且 ≤350 字、隱私檢查 0 命中、
向下相容原始 Zuvio 格式，
以及 **2.1 的名單流程**：PDF／Excel 名單解析（三種抽字排法＋表頭雜訊）、
端對端讀 `selftest\樣本_選課名單_合成.pdf`、有序號／無序號兩種編號規則、
兩題同一位同學拿同一個編號、名單外作答者 101 起且回寫對照表、
全班人數＝名單人數、未給名單被擋、`--no-roster` 放行、
隱私（含比對對照表真名與學號）0 命中。
詳細紀錄會寫到 `%TEMP%\HomeworkWordCloud_selftest.log`。

## 九、常見問題

**Q：按「跑本週」說找不到任何 xlsx。**
輸入資料夾選錯了，或檔案還在「下載」資料夾。也請確認副檔名是 `.xlsx` 不是 `.xls`。

**Q：log 出現「[略過] ×× 非作業檔（看起來是名冊…）」。**
正常。你把名冊檔也放進去了，程式認得出來並跳過它，不會影響其他題。

**Q：某一題沒有文字雲。**
那一題是選擇題／測驗題（回答只有幾個固定選項或「答對／答錯」），
或是有效字數太少。頁面會自動改成統計版面，不是壞掉。

**Q：文字雲的中文變成方框。**
電腦沒有中文字型。Windows 請確認有 `C:\Windows\Fonts\msjh.ttc`（微軟正黑體）；
macOS 請確認有 `/System/Library/Fonts/PingFang.ttc`。
（程式**不打包**微軟正黑體，那是授權問題。）

**Q：沒有產生縮圖。**
縮圖要靠 PowerPoint COM，只有 Windows 而且裝了 PowerPoint 才做得到，
沒有就自動略過，不影響簡報本身。

**Q：按「跑本週」跳出「必須先有名單才能處理」。**
你放進去的是**原始 Zuvio 匯出檔**（A 欄沒有「學生編號」）。
請在「名單／對照表檔」選一份名單或對照表，再按一次。
真的沒有名單才勾「沒有名單，改依檔案內出現順序編號」。

**Q：選課名單 PDF 說「讀不出名單」。**
那份 PDF 可能是掃描影像（沒有文字可抽），或格式和東華教務系統的選課名單差很多。
請改用 Excel／CSV 名單，只要有「學號」和「姓名」兩欄就好。

**Q：這學期中間有同學退選／加選，編號會亂掉嗎？**
不會。**不勾**「覆寫既有對照表」時，程式一律沿用既有對照表，
原有同學的編號完全不動；名單上沒有的作答者會被登記到「名單外作答者」
工作表，自 101 起，跨檔跨週都是同一個編號。

**Q：對照表可以和「姓名遮罩與學生編號」共用嗎？**
可以。兩支程式的檔名、工作表名、欄位名與 101 起的規則完全一樣，
同一份 `115-1_EC_學生名單與學生編號對照表.xlsx` 兩邊都讀得懂。

**Q：隱私檢查沒過怎麼辦？**
**先不要把輸出交出去。** 把執行紀錄整段複製下來回報，
並確認你丟進輸入資料夾的是「姓名遮罩與學生編號」的輸出檔。

## 十、隱私鐵律

1. 所有輸出檔一律用**學生編號**；姓名第 2 字改 O、學號與電子郵件每個字元都改 O。
2. 自由文字裡出現的同學姓名會被換成學生編號；**名單上的所有姓名都會被換掉**，
   即使那個檔案的姓名欄沒出現過他。連**題幹／子題題目**裡夾帶的電子郵件與
   9 碼以上數字也一起遮掉（真實匯出檔的題幹確實會夾帶聯絡信箱）。
3. 「學生編號連結姓名」與**學生名單與學生編號對照表**是唯一能還原身分的檔案，
   **只能留在本機**：不上傳雲端、不進 git、不外傳。
4. 交出去之前一定按一次 **[隱私檢查]**，確認 `0 命中`
   （有選對照表時會一併比對對照表內所有真實姓名與學號）。
5. 本程式不連網路、不上傳、不回傳任何資料。

## 十一、2.1 改了什麼（給已經在用 2.0 的人）

| 項目 | 2.0 | 2.1 |
|---|---|---|
| 學生編號 | 依檔案內出現順序，跨檔會變 | **依固定對照表**，整學期不變 |
| 原始 Zuvio 檔 | 直接跑 | **要先給名單／對照表**（或明確選「沒有名單」） |
| 名單來源 | 無 | Excel／CSV／東華選課名單 **PDF** |
| 名單外作答者 | 每次呼叫重新從 101 數 | **持久登記在對照表**，跨檔跨週一致 |
| 全班人數 | 名冊檔或不重複編號數 | **對照表人數優先** |
| 附錄概念矩陣 | 依字典序 | 依**編號數字**排序 |
| 隱私檢查 | 名冊姓名＋學號／email 樣式 | 再加上**對照表的真實姓名與學號** |
| 題幹遮罩 | 未處理 | 題幹／子題題目的 email 與 9 碼以上數字一併遮掉 |

**已經跑過 2.0 的週次不用重跑**；但 2.0 的輸出編號和 2.1 的對照表編號不一樣，
要跨週比較的話，請用 2.1 重跑一次舊週次（輸入檔還在就可以）。

## 十二、2.2 改了什麼（給已經在用 2.1 的人）

| 項目 | 2.1 | 2.2 |
|---|---|---|
| 每題重點 | 3 個 | **6 個**（候選不足就有幾個列幾個） |
| 覆蓋率欄位 | 整體、三個都提到 | 整體、**提到 ≥3 個**、**六個都提到** |
| 提問分類 | 2 類 | **4 類**（計算數據／操作應用／延伸探究／概念理解） |
| 題頁右欄 | 重點卡＋提問卡（上下兩張） | **六列重點卡＋ 2×2 四張提問小卡**；左欄文字雲改窄 |
| 底部橫幅 | 三個重點全列 | **前三大重點＋「另三個重點見右上表」**（單行） |
| 附錄 | 1 頁 × 3 題 × 3 欄 | **每頁 2 題 × 6 欄（①–⑥），最多 3 頁** |
| 逐字稿 | 三個重點＋兩類提問 | **六個重點（前三個講數字、後三個合併）＋四類則數＋一則代表句**；仍 ≤350 字 |
| 設定檔 | 無版本 | 加 `config_version`，舊 `settings.json` **自動升級** |

舊週次不用重跑；要比較「六個重點」的話再用 2.2 重跑一次即可（輸入檔還在就可以）。
